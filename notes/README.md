# notes/

Anotações de trabalho do Git HuttBr: o que ficou para depois, as decisões tomadas e o porquê.

Não confundir com `docs/`, que é o **manual do app** (renderizado dentro do app e no site). Nada desta pasta vai para o app nem para o site.

| Arquivo | O que guarda |
|---|---|
| [`backlog.md`](backlog.md) | O que ficou para depois, por área e severidade. É o ponto de partida ao retomar o trabalho |
| [`decisions.md`](decisions.md) | Decisões tomadas, com a data e o motivo, para não serem rediscutidas sem um fato novo |

Regras:

- Atualize no mesmo commit que conclui ou adia um item.
- Nada de fora do projeto: sem dados de outros projetos, máquinas, hosts ou pessoas.
- Segredos nunca entram aqui.
