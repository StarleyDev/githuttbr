# Первый запуск

При первом запуске GitHuttBr короткий мастер спрашивает то немногое, что меняет его поведение с первого коммита: кто вы в Git, где размещены ваши репозитории, нужен ли ИИ и как должно выглядеть приложение. Любой шаг можно оставить пустым, а всё, что он задаёт, позже меняется в **Настройках**.

![Шаг ИИ: CLI с подпиской найден на этом компьютере и проверен](../../screenshots/onboarding-ai.webp)

## Экран приветствия

Перед шагами экран приветствия предлагает **импортировать файл настроек** с другого компьютера. Ключи и токены из файла удаляются, если не отметить флажок, чтобы их сохранить, а экспорт с паролем запрашивает пароль прямо там. Импорт применяет файл и закрывает мастер — что содержит экспорт, см. в [Безопасность и секреты](security.md).

## Шаги

Левая колонка перечисляет шаги. Зелёная галочка отмечает заполненный шаг, прочерк — пройденный без заполнения, а подсвеченная строка — текущий.

| Шаг | Что задаёт | Где изменить потом |
|---|---|---|
| Идентичность Git | Имя профиля, а также имя и email в коммитах | Настройки → Профиль и личность |
| Аккаунты | Токены GitHub, GitLab, Azure DevOps, Bitbucket, Forgejo и собственных серверов, и приложение для **Открыть с помощью…** | Настройки → Подключённые аккаунты; приложение — в Настройки → Git и синхронизация |
| Искусственный интеллект | Один аккаунт ИИ, сделанный используемым | Настройки → ИИ |
| Внешний вид | Тема и светлый, тёмный или автоматический режим | Настройки → Темы |
| Готово | Ничего нового — сводка настроенного | — |

**Пока пропустить** закрывает мастер на любом шаге и сохраняет уже введённое.

## Шаг ИИ

ИИ необязателен. Выберите одну из трёх карточек или **Пропустить, без ИИ**:

| Карточка | Что использует | Что нужно |
|---|---|---|
| Моя подписка | Claude Code или Codex, вход по вашему тарифу | Установленный CLI с выполненным входом |
| API-ключ | OpenAI, Anthropic, Gemini, Groq, OpenRouter или Mistral | Ключ от провайдера |
| На моём компьютере | Ollama или LM Studio локально — ничего не покидает машину | Запущенный сервер |

Если на компьютере найден Claude Code или Codex, карточка подписки называет его и версию, а выбор карточки его проверяет: один короткий промпт, затем **Проверено: ответ за N с. Готово к работе.** Если ничего не найдено или CLI без входа, карточка показывает ту же настройку подключения, что и [Настройки → ИИ](ai.md).

Для API-ключа или локального сервера кнопка **Продолжить** проверяет подключение, запрашивая список моделей, и сохраняет только ответивший аккаунт.

Шаг сохраняет обычный аккаунт ИИ — так же, как его пишут Настройки, — с отметкой **Используется**: откройте Настройки → ИИ, и он там, его можно переименовать, использовать лишь для части функций или удалить. Несколько аккаунтов, модель для каждой функции и стиль ИИ настраиваются там, а не в мастере.

## Ограничения

- **Проверка подписки стоит одного промпта.** Она засчитывается в ваш тариф, как любой запрос. Запускается только при выборе карточки или нажатии **Проверить снова**.
- **Распознаются только Claude Code и Codex.** Gemini CLI и Devin работают как обычные CLI-аккаунты, которые добавляются в Настройки → ИИ.
- **Локальный сервер уже должен работать.** Мастер не запускает Ollama или LM Studio и не скачивает модели.
- **Мастер запускается один раз.** После закрытия всё заданное живёт в Настройках; открыть мастер снова нельзя.
