# التشغيل الأول

عند فتح GitHuttBr أول مرة، يسأل معالج قصير عن الأشياء القليلة التي تغيّر سلوكه منذ أول التزام: من أنت في Git، وأين تُستضاف مستودعاتك، وهل تريد استخدام الذكاء الاصطناعي، وأي مظهر تفضّل. يمكن ترك أي خطوة فارغة، وكل ما يضبطه يمكن تغييره لاحقًا من **الإعدادات**.

![خطوة الذكاء الاصطناعي: واجهة CLI باشتراك عُثر عليها في هذا الحاسوب واختُبرت](../../screenshots/onboarding-ai.webp)

## شاشة الترحيب

قبل الخطوات، تعرض شاشة الترحيب **استيراد ملف إعدادات** من حاسوب آخر. تُزال المفاتيح والرموز من الملف ما لم تحدد المربع للإبقاء عليها، ويطلب التصدير المحمي بكلمة مرور كلمته في المكان نفسه. يطبّق الاستيراد الملف ويغلق المعالج — راجع [الأمان والأسرار](security.md) لمعرفة ما يحويه التصدير.

## الخطوات

يعرض العمود الأيسر الخطوات. علامة الصح الخضراء لخطوة ملأتها، والشرطة لخطوة تجاوزتها دون ملء، والصف المميّز هو مكانك الحالي.

| الخطوة | ما تضبطه | أين تغيّرها لاحقًا |
|---|---|---|
| هوية Git | اسم الملف الشخصي، والاسم والبريد في التزاماتك | الإعدادات ← الملف الشخصي والهوية |
| الحسابات | رموز GitHub وGitLab وAzure DevOps وBitbucket وForgejo والخوادم الذاتية، وتطبيق **فتح باستخدام…** | الإعدادات ← الحسابات المتصلة؛ والتطبيق في الإعدادات ← Git والمزامنة |
| الذكاء الاصطناعي | حساب ذكاء اصطناعي واحد، مُعيَّن قيد الاستخدام | الإعدادات ← الذكاء الاصطناعي |
| المظهر | السمة والوضع الفاتح أو الداكن أو التلقائي | الإعدادات ← السمات |
| تم | لا شيء جديد — ملخص لما أُعدّ | — |

**تخطَّ الآن** يغلق المعالج في أي خطوة ويحتفظ بما أدخلته.

## خطوة الذكاء الاصطناعي

الذكاء الاصطناعي اختياري. اختر إحدى البطاقات الثلاث، أو **تخطَّ، دون ذكاء اصطناعي**، الذي يوقف الذكاء الاصطناعي
إلى أن تعدّه في [الإعدادات ← الذكاء الاصطناعي](ai.md):

| البطاقة | ما تستخدمه | ما تحتاجه |
|---|---|---|
| اشتراكي | Claude Code أو Codex مسجَّل الدخول بخطتك | واجهة CLI مثبّتة ومسجَّلة الدخول |
| مفتاح API | OpenAI أو Anthropic أو Gemini أو Groq أو OpenRouter أو Mistral | مفتاح من المزوّد |
| على حاسوبي | Ollama أو LM Studio محليًا — لا شيء يغادر الجهاز | خادم قيد التشغيل |

حين يُعثر على Claude Code أو Codex في هذا الحاسوب، تذكر بطاقة الاشتراك أيهما وإصداره، واختيار البطاقة يختبره: طلب قصير واحد، ثم **تم الاختبار: أجاب خلال N ث. جاهز للاستخدام.** إن لم يُعثر على أي منهما، أو لم يُسجَّل دخول CLI، تعرض البطاقة إعداد الاتصال نفسه الموجود في [الإعدادات ← الذكاء الاصطناعي](ai.md).

لمفتاح API أو خادم محلي، يختبر **متابعة** الاتصال بسرد نماذج المزوّد، ولا يحفظ إلا حسابًا أجاب.

ما تحفظه الخطوة حساب ذكاء اصطناعي عادي، مكتوب كما تكتبه الإعدادات ومُعيَّن **قيد الاستخدام**: افتح الإعدادات ← الذكاء الاصطناعي تجده هناك، جاهزًا لإعادة التسمية أو الاستخدام لبعض الميزات فقط أو الحذف. الحسابات المتعددة ونموذج لكل ميزة وأسلوب كتابة الذكاء الاصطناعي تُضبط هناك، لا في المعالج.

## الحدود

- **اختبار الاشتراك يكلّف طلبًا.** يُحتسب من استخدام خطتك كأي طلب. لا يعمل إلا عند اختيار البطاقة أو الضغط على **اختبر مجددًا**.
- **لا يُكتشف إلا Claude Code وCodex.** يعمل Gemini CLI وDevin كحسابات CLI عادية تضيفها من الإعدادات ← الذكاء الاصطناعي.
- **يجب أن يكون الخادم المحلي قيد التشغيل مسبقًا.** لا يشغّل المعالج Ollama ولا LM Studio، ولا ينزّل نماذج.
- **يعمل المعالج مرة واحدة.** بعد إغلاقه يبقى كل ما ضبطه في الإعدادات؛ ولا سبيل إلى فتح المعالج مجددًا.
