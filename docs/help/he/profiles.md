# פרופילים

פרופיל אוגד **זהות Git** (שם וכתובת דוא״ל) יחד עם **טוקני האינטגרציה** שלה.
החליפו פרופיל ושניהם משתנים יחד — הקומיטים נכתבים בשם הנכון וקריאות ה־API
משתמשות בחשבון הנכון.

שימושי כשאותה מכונה מטפלת גם במאגרי עבודה וגם באישיים, או כשיש לכם שני חשבונות
GitHub.

![פרופיל: זהות git בצד אחד, טוקני האינטגרציה שלה בצד השני](../../screenshots/settings-profiles.webp)

## עריכת פרופיל, שימוש בפרופיל

ההגדרות מחלקות את הדפים לשניים. **הפרופיל הזה** מכיל את הדפים שמשתנים עם
הפרופיל — **פרופיל** ו**אינטגרציות**. **האפליקציה** מכילה את כל השאר, שחל בכל
פרופיל ואומר זאת בראש הדף.

שני דפי הפרופיל נפתחים בסרגל: *עורכים את הפרופיל* ובורר. הבורר קובע איזה פרופיל
אתם **עורכים**; הוא לא משנה את הפרופיל שהאפליקציה **משתמשת** בו. כשהם שונים, פס
בצבע ענבר אומר זאת — *אתם עורכים את עבודה. האפליקציה משתמשת ב-אישי* — עם
**להשתמש בפרופיל הזה** כדי לעבור. זה הרגע שבו הכי קל לקשר חשבון לפרופיל הלא נכון,
ולכן דף האינטגרציות גם מציין את הפרופיל בכל כרטיס ועל הכפתור עצמו: **קישור לפרופיל
עבודה**, והאישור חוזר על כך. יצירה ומחיקה נמצאות באותו סרגל; מחיקה שואלת קודם.

![עריכת הפרופיל Work בזמן שהאפליקציה משתמשת בפרופיל אחר: הפס בצבע ענבר, וכפתור הקישור שנוקב בשם Work](../../screenshots/settings-profile-band.webp)

## הבינה המלאכותית משותפת

פרופיל לא צריך בינה מלאכותית משלו: [בינה מלאכותית
כללית](ai.md#בינה-מלאכותית-אחת-לכל-הפרופילים) אחת משרתת את כל הפרופילים, ופרופיל
עובר לבינה משלו רק כשהוא חייב. הבחירה חלה על הכול: פרופיל על הבינה הכללית גם
כותב כפי שהבינה הכללית מוגדרת — סגנון ה-commit, כללים נוספים לקומיטים, צ׳אט
המאגר. פרופיל שצריך סגנון אחר מקבל בינה משלו, העתק של הכללית שהוא יכול לשנות אחר
כך. את כל זה עורכים בדף **AI**; דף הפרופיל רק אומר באיזו בינה הפרופיל משתמש
ומקשר לשם.

## לכל פרופיל החשבונות שלו

מלבד אסימון, פרופיל יכול **לקשר** התחברות שכבר קיימת במחשב — מה-credential
helper של git או מ-GitHub CLI — בהגדרות → אינטגרציות. קישור שייך לפרופיל אחד:
פרופיל חדש מתחיל מנותק, וחשבון שכבר שייך לפרופיל אחר נדחה, כך ששני פרופילים
יכולים להחזיק שני חשבונות GitHub (או Azure DevOps) זה לצד זה. ראו
[אחסון](hosting.md).

## קשירה לכל מאגר

מאגר יכול להיות **קשור לפרופיל**, כך שהבאה ברקע עליו תמיד מתאמתת בתור החשבון
הנכון — גם בזמן שאתם מסתכלים על מאגר ששייך לאחר.

הטוקנים חיים ב[מחזיק המפתחות של מערכת ההפעלה](security.md) שלכם, לעולם לא בקובץ
ההגדרות.

**ראו גם:** [אבטחה וסודות](security.md) · [אירוח](hosting.md)
