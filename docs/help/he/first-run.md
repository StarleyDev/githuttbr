# הפעלה ראשונה

בפעם הראשונה ש־GitHuttBr נפתח, אשף קצר שואל על הדברים המעטים שמשנים את התנהגותו מהקומיט הראשון: מי אתם ב־Git, היכן המאגרים שלכם מאוחסנים, האם להשתמש ב־AI ואיך זה ייראה. כל שלב יכול להישאר ריק, וכל מה שהוא קובע אפשר לשנות אחר כך ב**הגדרות**.

![שלב ה־AI: ממשק CLI במינוי שנמצא במחשב הזה ונבדק](../../screenshots/onboarding-ai.webp)

## מסך הפתיחה

לפני השלבים, מסך הפתיחה מציע **לייבא קובץ הגדרות** ממחשב אחר. מפתחות וטוקנים מוסרים מהקובץ אלא אם מסמנים את התיבה לשמור אותם, וייצוא מוגן בסיסמה מבקש אותה במקום. הייבוא מחיל את הקובץ וסוגר את האשף — מה ייצוא מכיל, ראו [אבטחה וסודות](security.md).

## השלבים

העמודה השמאלית מציגה את השלבים. וי ירוק מסמן שלב שמילאתם, קו — שלב שעברתם בלי למלא, והשורה המודגשת היא המקום שבו אתם.

| שלב | מה הוא קובע | איפה לשנות אחר כך |
|---|---|---|
| זהות Git | שם הפרופיל, והשם והאימייל בקומיטים שלכם | הגדרות ← פרופיל וזהות |
| חשבונות | טוקנים ל־GitHub,‏ GitLab,‏ Azure DevOps,‏ Bitbucket,‏ Forgejo ולשרתים בניהול עצמי, והאפליקציה של **פתיחה באמצעות…** | הגדרות ← חשבונות מחוברים; האפליקציה בהגדרות ← Git וסנכרון |
| בינה מלאכותית | חשבון AI אחד, שהוגדר בשימוש | הגדרות ← AI |
| מראה | ערכת נושא ומצב בהיר, כהה או אוטומטי | הגדרות ← ערכות נושא |
| סיום | שום דבר חדש — סיכום של מה שהוגדר | — |

**לדלג בינתיים** סוגר את האשף בכל שלב ושומר את מה שכבר הזנתם.

## שלב ה־AI

ה־AI אופציונלי. בחרו אחד משלושת הכרטיסים, או **דילוג, בלי AI**:

| כרטיס | במה הוא משתמש | מה הוא צריך |
|---|---|---|
| המנוי שלי | Claude Code או Codex, מחוברים עם המינוי שלכם | CLI מותקן ומחובר |
| מפתח API | OpenAI,‏ Anthropic,‏ Gemini,‏ Groq,‏ OpenRouter או Mistral | מפתח מהספק |
| במחשב שלי | Ollama או LM Studio, מקומית — שום דבר לא יוצא מהמחשב | שרת שהופעל |

כש־Claude Code או Codex נמצאים במחשב הזה, כרטיס המינוי אומר איזה מהם ואת הגרסה, ובחירת הכרטיס בודקת אותו: הנחיה קצרה אחת, ואז **נבדק: ענה תוך N שנ׳. מוכן לשימוש.** אם אף אחד לא נמצא, או שה־CLI לא מחובר, הכרטיס מציג את אותה הגדרת חיבור כמו [הגדרות ← AI](ai.md).

עבור מפתח API או שרת מקומי, **המשך** בודק את החיבור על ידי הצגת המודלים של הספק, ושומר רק חשבון שענה.

מה שהשלב שומר הוא חשבון AI רגיל, שנכתב כמו שההגדרות כותבות אותו ומסומן **בשימוש**: פתחו הגדרות ← AI והוא שם, מוכן לשינוי שם, לשימוש רק בחלק מהתכונות או למחיקה. חשבונות נוספים, מודל לכל תכונה ואופן הכתיבה של ה־AI נקבעים שם, לא באשף.

## מגבלות

- **בדיקת המינוי עולה הנחיה אחת.** היא נספרת במכסת המינוי כמו כל בקשה. היא רצה רק כשבוחרים את הכרטיס או לוחצים **לבדוק שוב**.
- **רק Claude Code ו־Codex מזוהים.** Gemini CLI ו־Devin עונים כחשבונות CLI רגילים, שמוסיפים בהגדרות ← AI.
- **שרת מקומי חייב לרוץ כבר.** האשף לא מפעיל את Ollama או LM Studio ולא מוריד מודלים.
- **האשף רץ פעם אחת.** אחרי שהוא נסגר, כל מה שקבע נמצא בהגדרות; אין דרך לפתוח את האשף שוב.
