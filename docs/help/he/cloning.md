# שכפול

**מאגר חדש ← שכפול**, או `⌘K` ← *שכפול*. הדביקו כתובת URL, או התחברו אל GitHub,
GitLab, Bitbucket או Azure DevOps ובחרו מתוך המאגרים שלכם — הטוקן של
[הפרופיל](profiles.md) הנבחר משמש לשכפול ואז נזרק, ולעולם אינו נכתב אל
`.git/config`.

בחרו תיקיית אב ושם; השורה מתחת לשדות מראה בדיוק היכן המאגר ינחת. תיקייה שכבר
קיימת נדחית במקום להתמזג לתוכה.

## כמה מאגרים בבת אחת

הכנת מחשב חדש, או הורדת כל השירותים של צוות, חייבו בעבר לפתוח את החלון הזה פעם
אחת לכל מאגר. בלשונית של שירות מארח, סמנו את התיבה של כל מאגר שאתם רוצים, או
לחצו **בחירת כל המוצגים** כדי לקחת את כל מה שהמסנן תואם. לחיצה על שורה (לא על
התיבה שלה) עדיין בוחרת רק אותה.

כשמסומן יותר מאחד, החלון משכפל את כולם לאותה תיקיית אב, כל אחד לתיקייה בשם
המאגר. הנתיבים מוצגים לפני שמתחילים. אם לשניים יש אותו שם (`org-a/app`
ו־`org-b/app`), שניהם מקבלים את שם הבעלים בשם התיקייה (`org-a-app`,
`org-b-app`) במקום להתחרות על תיקייה אחת.

![לשונית GitHub בחלון השכפול עם שלושה מאגרים מסומנים, התיקיות שאליהן ינחתו מוצגות מתחת לתיקיית האב, וכפתור שכפול 3 מאגרים](../../screenshots/clone-multi-select.webp)

האצווה עוברת ישר למגש שבפינה. שלושה שכפולים רצים במקביל והשאר ממתינים במצב
*בתור*; לכל אחד כפתור ביטול משלו. כל מאגר נפתח בלשונית ברגע שהוא מסתיים.

מגבלות:
- **הענף לצ׳קאאוט** מוסתר באצווה: לשם ענף אין משמעות בין מאגרים שונים, ולכן כל
  אחד מקבל את ענף ברירת המחדל שלו. שאר אפשרויות המתקדם (חלקי, רדוד, ענף בודד,
  תת־מודולים) חלות על כולם.
- בחירה מרובה עובדת רק בלשוניות של השירותים המארחים. לשונית ה־URL מקבלת כתובת
  אחת.
- כישלון אחד לא עוצר את האחרים. מאגר שהתיקייה שלו כבר קיימת נכשל עם שגיאה משלו,
  והשאר ממשיכים.

## מתקדם — צמצום השכפול

כל מה שתחת **מתקדם** כבוי כברירת מחדל: אל תיגעו בו ותקבלו שכפול רגיל ומלא. הוא
מצדיק את מקומו במאגרים שבהם ״מלא״ פירושו עשרים דקות וכמה ג׳יגה־בייטים.

![חלון השכפול כשמתקדם פתוח: חלקי, רדוד, ענף בודד, תת־מודולים ובורר ענפים](../../screenshots/clone-advanced.webp)

| אפשרות | מה git עושה | מה זה עולה |
|--------|---------------|---------------|
| **שכפול חלקי** | `--filter=blob:none` | היסטוריה מלאה, בלי תוכן הקבצים. הבלובים מגיעים לפי דרישה, ולכן פתיחת קובץ ישן דורשת רשת. |
| **שכפול רדוד** | `--depth=N` | רק N הקומיטים האחרונים קיימים. blame, log, bisect ו־range-diff נעצרים בחתך. |
| **רק ענף אחד** | `--single-branch` | שאר הענפים נשארים ברימוט עד שתביאו אותם. |
| **שכפול תת־מודולים** | `--recurse-submodules` | גם כל תת־מודול עובר צ׳קאאוט — יותר זמן עכשיו, בלי תיקיות חסרות אחר כך. |
| **הענף לצ׳קאאוט** | `--branch <name>` | מתחיל על הענף הזה במקום על ברירת המחדל של הרימוט. |

**חלקי לפני רדוד.** שכפול חלקי שומר כל קומיט — ההיסטוריה נשארת ניתנת לחיפוש, ורק
תוכן הקבצים מובא בעצלתיים. שכפול רדוד באמת זורק היסטוריה: `git log` נגמר בחתך
ו־blame לא רואה מעבר לו. אם אתם משכפלים מונורפו כדי לעבוד בו, חלקי הוא בדרך כלל
מה שאתם רוצים.

רדוד ניתן לביטול: הפקודה `git fetch --unshallow` ב[טרמינל](terminal.md) ממלאת
את ההיסטוריה בחזרה.

### בחירת הענף

הקלידו שם ענף, או לחצו **רשימת ענפים** כדי לשאול את הרימוט מה יש לו
(`git ls-remote --heads`) ולבחור מרשימה נפתחת. זו נסיעת רשת אחת, שנעשית רק
כשלוחצים על הכפתור — שום דבר לא נשאל בזמן ההקלדה.

אם הרישום נכשל — כתובת פרטית בלי טוקן עדיין, שגיאת הקלדה, אין רשת — השדה נשאר
תיבת טקסט רגילה, והשכפול עצמו מדווח על השגיאה האמיתית.

### שתי הערות על הדגלים

- **`--depth` גורר `--single-branch`.** בשכפול רדוד, השארת *רק ענף אחד* לא
  מסומנת היא מה שמבקש את שאר הענפים בחזרה (`--no-single-branch`), ולכן הרמז
  שמתחתיה משתנה.
- **שכפול תיקייה מקומית** מתעלם בדרך כלל מ־`--depth` לגמרי, כי git יוצר קישורים
  קשיחים למחסן האובייקטים במקום להביא אותו. Gitcito משכפל דרך כתובת `file://`
  כשאתם מבקשים עותק רדוד של מאגר מקומי, כך שהעומק שביקשתם הוא העומק שתקבלו.

## התקדמות, רקע וביטול

הסרגל מדווח את מה ש־git מדווח: ספירה, דחיסה, קבלה, פענוח, צ׳קאאוט. שלב שאינו
יכול לדווח על סך הכול מציג סרגל בלתי מוגדר במקום אחוז מזויף.

שכפול גדול לוקח דקות, ולחיצה תועה מחוץ לחלון עלתה לכם בעבר בכולן. עכשיו סגירת
החלון — **הרצה ברקע**, `Esc`, ה־✕ או לחיצה מחוצה לו — רק מסתירה אותו: השכפול
ממשיך ועובר לכרטיס קטן בפינה התחתונה, עם אותו סרגל התקדמות. בינתיים אפשר להתחיל
שכפול נוסף; כל אחד מקבל כרטיס משלו.

![מגש השכפולים בפינה התחתונה: שלושה שכפולים בקבלה, בפענוח ובספירה, רביעי בתור, לכל אחד כפתור ביטול משלו](../../screenshots/clone-tray.webp)

בחרתם במאגר הלא נכון? **ביטול השכפול** בחלון, או ה־✕ בכרטיס שלו, עוצר את git
ומוחק את התיקייה הכתובה למחצה. שום דבר אחר לא נוגעים בו — התיקייה לא הייתה קיימת
לפני תחילת השכפול, וזה נבדק מראש. שכפול שבוטל אי אפשר לחדש; הפעלה מחדש מתחילה
מאפס.

כשהוא מסתיים, המאגר החדש נפתח בלשונית, מוצמד לפרופיל שאיתו שכפלתם, בין שהחלון
עדיין פתוח ובין שלא.

השכפולים רצים בתוך האפליקציה, ולכן יציאה מ־Gitcito עוצרת אותם. היציאה לא ממתינה
לניקוי, כך שהתיקייה הכתובה למחצה עלולה להישאר — מחקו אותה לפני שתשכפלו לשם שוב,
כי החלון דוחה תיקייה שקיימת.
