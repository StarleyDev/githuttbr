# 首次运行

GitHuttBr 第一次打开时，一个简短的向导会询问从第一次提交起就影响其行为的几件事：你在 Git 中是谁、仓库托管在哪里、是否使用 AI，以及外观。每一步都可以留空，向导设置的一切之后都能在 **设置** 中修改。

![AI 步骤：在这台电脑上找到并测试过的订阅 CLI](../../screenshots/onboarding-ai.webp)

## 欢迎界面

在各步骤之前，欢迎界面提供从另一台电脑 **导入设置文件**。文件中的密钥和令牌会被去除，除非你勾选保留；受密码保护的导出会当场要求输入密码。导入会应用该文件并关闭向导 —— 导出包含什么，见 [安全与机密](security.md)。

## 步骤

左栏列出各步骤。绿色对勾表示已填写的步骤，短横线表示未填写就跳过的步骤，高亮的一行是当前所在步骤。

| 步骤 | 设置内容 | 之后在哪里修改 |
|---|---|---|
| Git 身份 | 配置档案名称，以及提交中的姓名和邮箱 | 设置 → 个人资料与身份 |
| 账户 | GitHub、GitLab、Azure DevOps、Bitbucket、Forgejo 及自托管服务器的令牌，以及 **打开方式…** 使用的应用 | 设置 → 已连接的账户；应用在 设置 → Git 与同步 |
| 人工智能 | 一个设为使用中的 AI 账户 | 设置 → AI |
| 外观 | 主题，以及浅色、深色或自动模式 | 设置 → 主题 |
| 完成 | 没有新设置 —— 已设置内容的摘要 | — |

**暂时跳过** 会在任意步骤关闭向导，并保留已填写的内容。

## AI 步骤

AI 是可选的。选择三张卡片之一，或 **跳过，不用 AI**，这会关闭 AI，
直到你在 [设置 → AI](ai.md) 中设置它：

| 卡片 | 使用什么 | 需要什么 |
|---|---|---|
| 我的订阅 | 已用你的套餐登录的 Claude Code 或 Codex | 已安装并登录的 CLI |
| API 密钥 | OpenAI、Anthropic、Gemini、Groq、OpenRouter 或 Mistral | 提供商的密钥 |
| 在我的电脑上 | 在本地运行的 Ollama 或 LM Studio —— 数据不离开本机 | 已启动的服务器 |

在这台电脑上找到 Claude Code 或 Codex 时，订阅卡片会显示是哪一个及其版本，选择该卡片即会测试：发送一条简短提示，然后显示 **已测试：N 秒内回复。可以使用。** 如果都没有找到，或 CLI 未登录，卡片会显示与 [设置 → AI](ai.md) 相同的连接设置。

对于 API 密钥或本地服务器，**继续** 会通过列出提供商的模型来测试连接，只保存有响应的账户。

这一步保存的是普通的 AI 账户，写入方式与设置相同，并设为 **使用中**：打开 设置 → AI 就能看到，可以重命名、仅用于部分功能或删除。多个账户、按功能选择模型以及 AI 的写作方式都在那里设置，而不是在向导中。

## 限制

- **订阅测试会消耗一条提示。** 与任何请求一样计入你的套餐用量。只有在选择卡片或点击 **重新测试** 时才运行。
- **只检测 Claude Code 和 Codex。** Gemini CLI 和 Devin 作为普通 CLI 账户使用，需在 设置 → AI 中添加。
- **本地服务器必须已在运行。** 向导不会启动 Ollama 或 LM Studio，也不会下载模型。
- **向导只运行一次。** 关闭后，它设置的一切都在设置中；没有办法再次打开向导。
