# 快速上手

GitHuttBr 打开一个文件夹，把它的历史摊开给你看。在你亲口要求之前，它不会往你的
仓库里写任何东西。

![刚打开的仓库，还没有任何提交](../../screenshots/empty-repo.webp)

## 打开一个仓库

![打开仓库：打开、克隆或创建，下面是扫描到的仓库和最近的仓库](../../screenshots/open-repository.webp)

- **把文件夹拖**到窗口上，或者在欢迎界面点 **打开仓库**。选择器可以一次选多个
  文件夹：用 ⌘-点击或 Shift-点击选中它们，每个都会在自己的标签页里打开（或者加入
  你打开选择器时所在的分组）。一次选了多个时，已经打开的仓库、或者不是 Git 仓库的
  文件夹会被跳过，并在一条消息里点名，其余的照样打开。macOS 的选择器没法提前把
  已打开的仓库置灰：Electron 没有开放面板的逐文件夹钩子，所以检查发生在你点了
  “打开”之后。
- 三个按钮下面的 **扫描到的仓库**，列出你让 GitHuttBr 扫描的那些文件夹里的每个
  仓库——勾选几个一次打开，或者双击其中一个。添加或移除这些文件夹也在这里。
  见[仓库](repositories.md#扫描到的仓库)。
- **点错了？** 从“打开仓库”打开的克隆、创建、创建分组和扫描到的仓库，标题旁边都有
  一个 **返回** 箭头，可以回到那里。
- 从 URL 或者直接从你的代码托管平台**克隆**一个——想让一个巨大的仓库克隆得快
  一些，可以看[克隆](cloning.md)里的那些选项。
- 在终端里执行 `githuttbr .`，会把当前文件夹在已经运行的应用里打开——见
  [命令行](cli.md)。
- 单独一个还不是 Git 仓库的文件夹同样能打开，应用会主动提出替你初始化。

## 三个面板

| 面板 | 里面有什么 |
|---|---|
| 左侧 | 分支、远程、标签、贮藏、工作树——以及对应工作区的 **文件** 标签页 |
| 中间 | 提交图，以及你从图里选中的任何东西 |
| 右侧 | 提交编辑区，或者所选提交的详情 |

## 其余的东西去哪儿找

两条路，通向同一批地方：

- **`⌘K`**（`Ctrl+K`）——命令面板。想要什么就打什么；它也能直接跳到分支、提交
  和文件。
- 工具栏里的 **工具**——同一套以仓库为范围的功能，只不过做成了菜单，长尾部分
  折叠成分组，好让它保持可读。

![工具菜单：常用工具在前，其余的分组收纳](../../screenshots/tools-menu.webp)

窗口变窄时，操作栏不再争抢空间：放不下的按钮会按原顺序折叠进末尾的 **更多** 下拉菜单，各自的子菜单照旧保留。把窗口拉宽，它们又会回到栏上。

一条路能到的地方，另一条路也能到，所以这里没有什么是只有高手才找得到的。

## 你的第一次提交

1. 改一个文件。它会出现在 **未暂存** 下面。
2. 暂存它——整个文件、一个变更块，或者[单独几行](staging.md)。
3. 写一条消息，按 **提交**。

GitHuttBr 里其余的一切都是可选的。
