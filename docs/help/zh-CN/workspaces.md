# 工作空间、标签页与分组

三个层级，由松到紧。

## 标签页

一个仓库，一个标签页。用 <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> 打开新标签页选择器，
用 <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> 关闭当前标签页。你也可以拖动来重新排序、
中键点击关闭，或者按 <kbd>⌘⇧T</kbd> 重新打开最近关掉的那个。右键点击一个仓库
标签页（或[分组](#分组)里的一枚徽章），可以打开
[仓库上下文菜单](repo-menu.md)——别名、工作树、GitHub、终端、显示、编辑器，最下面是 **关闭此仓库** 和
**关闭其他**（分组里的徽章则改为提供移除）。关掉最后一个标签页
之后，<kbd>⌘W</kbd> 关的就是窗口了。标签页上的一个圆点表示有未提交的工作；换一
种圆点则表示有冲突。

如果弹出了关闭警告，<kbd>Escape</kbd> 永远是取消。只有在标签页干净的时候
<kbd>Enter</kbd> 才代表确认——一旦存在未提交的变更或者冲突，这个警告就故意逼你
去够那个按钮，好让 <kbd>⌘W</kbd> 之后的一次误触关不掉你还攥在手里的工作。

### 标签页尺寸

默认情况下（**设置 → 布局 → 标签页尺寸 → 自适应**），标签页的行为和浏览器一样：标签条
放不下时，它们会等比收缩到一个最小宽度，只有连这个下限也到了才开始滚动。**固定** 恢复
经典行为——每个标签页保持其内容宽度，一旦放不下全部，标签条就滚动。

### 转到某个仓库

打开十个或更多仓库时，在标签条里找一个就得滚动，<kbd>⌘1</kbd>–<kbd>⌘9</kbd> 只到第九个
标签页，而 [命令面板](search.md) 会把打开的仓库和所有操作混在一起。按 <kbd>⌘J</kbd> /
<kbd>Ctrl+J</kbd>（或 **显示 → 转到仓库…**），输入它的名称、文件夹或分支的几个字母，再按
<kbd>Enter</kbd>。

![仓库切换器，最近使用的排在前面](../../screenshots/repo-switcher.webp)

列表里只有打开的仓库，包括分组成员，按你最后查看的顺序排列。你刚离开的那个排在最前，所以
<kbd>⌘J</kbd> <kbd>Enter</kbd> 就能回到它。每一行都带着它的标签页所显示的内容：分支、
未提交工作或冲突的圆点、所在的分组，以及它有的话 <kbd>⌘1</kbd>–<kbd>⌘9</kbd> 快捷键。
当前屏幕上的仓库淡显在最下面。切换器背后不会变暗；点击外面或按 <kbd>Esc</kbd> 即可关闭。

没有任何打开的仓库匹配时，最后一行 **在所有仓库中查找** 会把你的搜索带到
[仓库](repositories.md) 页面。快捷键可以在 **设置 → 快捷键** 中重新绑定。

*限制：* 顺序只在本次会话中记住，所以重启后会从标签页顺序开始。在两个标签页中打开的仓库只
列出一次，位于它的第一个标签页。其他 [工作空间](#工作空间) 中的仓库不会列出——请先切换工作
空间，或使用仓库页面。

## 分组

把相关的仓库打包成一个有名字、有颜色标识的**分组标签页**。进入分组后会多出一行，
每个仓库一枚徽章，而分组本身可以一次性**全部获取**或**全部拉取**。

要开始一个分组，右键点击一个仓库标签页 → *新建分组…*：该标签页就地变成一个包含此仓库的
分组。有了分组之后，同一个菜单会显示为 *添加到分组 →*，并列出打开的分组。把仓库标签页拖到
分组徽章上也能做到同样的事。

*新建分组…* 会同时询问名称和颜色。颜色从还没有被任何打开的分组使用的颜色里随机选起，这样
分组不会都以同一种颜色开始。

![新建分组对话框，名称和颜色一起选择](../../screenshots/new-group-dialog.webp)

要给分组换颜色，右键点击它：十种颜色以一排圆点的形式出现在菜单中，当前颜色外有一个圆环，
点一下即可应用。圆点下方的 *自定义颜色…* 会打开一个选择任意其他颜色的取色器。文件夹和仓库
页面中的分区也使用同一排颜色。

![分组的右键菜单：颜色行、自定义颜色…、取消分组和关闭分组](../../screenshots/group-color-menu.webp)

要解散一个分组，右键点击它 → **取消分组**。每个仓库都会在分组原来的位置变成普通标签页，
并保留它打开的页面。**关闭分组** 则会关闭分组以及其中的所有仓库。文件夹不会在取消分组后
保留：它们只存在于分组之内。

![装着好几个仓库的分组标签页](../../screenshots/repo-groups.webp)

分组里可以放**文件夹，而且可以任意层级地嵌套**：右键点击分组 → *新建文件夹…*，
然后把仓库拖到文件夹徽章上。每个文件夹有自己的颜色，可以折叠成一枚带计数的徽章，
会汇总它里面所有东西的状态圆点，并且能对整棵子树做获取或拉取。

![分组标签栏里的文件夹，每个都是一枚带计数的徽章——Internal 嵌套在 Services 里面](../../screenshots/nested-folders.webp)

> 文件夹只负责整理。删掉一个文件夹，只会把它里面的仓库提到上一层——它绝不会关闭
> 任何仓库。

要添加分组里还没有的仓库，点击分组名称旁的 **+**。即使分组中的某个仓库正打开着，它也会显示分组自己的页面 — 打开文件夹、克隆、新建或选择最近的仓库；点击某个标签即可回到该仓库。

## 属于某个仓库的页面

有些页面本身不是独立的东西：一个仓库的 [wiki](repo-wiki.md)、它的
[洞察](insights.md)、某次启动会话公布的[开发工具](devtools.md)。它们不占标签页 ——
它们以小标签的形式出现在仓库自己身上：一个图标加一个说明是哪个页面的词（*CI*、*PR*、
*Wiki*、拉取请求用 *#482*、发布用其标签）。完整名称在工具提示里，过长的标签或标题会用
省略号截断。

- **点图标**显示那个页面。**再点一次 —— 或者点仓库的名字 ——** 回到仓库。页面打开
  期间，名字会带上手型光标，悬停时还有一小块底色：那就是回去的路。
- **把鼠标放在图标上**，会出现只关掉这一个页面的 ✕。
- 在**分组**里，图标待在它所属仓库的小条上，而且只在那个仓库被选中时才出现。选中
  组里另一个仓库，显示的是*那个*仓库，而不是邻居的工具。
- 再次打开同一个页面会点亮它已有的图标，而不是再加一个。

一个哪里都没打开的仓库没有图标可挂，所以它的页面会退回成一个独立标签页 —— 打开
一个东西，总得真的打开点什么。

## 工作空间

一个工作空间就是**一整条保存下来的标签栏**。切换会把所有标签页一次换掉：`Work`
和 `Personal` 从此互不打扰。

工作空间的名字在左上角，紧挨着 Gitcito 的标志。点它可以切换、新建、重命名、重新
排序或删除。旁边那个仪表盘图标，会为你当前所在的工作空间打开
[任务中心](mission-control.md)。
