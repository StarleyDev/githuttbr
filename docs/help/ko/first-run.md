# 첫 실행

GitHuttBr를 처음 열면 짧은 마법사가 첫 커밋부터 동작을 바꾸는 몇 가지를 묻습니다. Git에서 당신이 누구인지, 저장소가 어디에 호스팅되는지, AI를 쓸지, 어떤 모양을 원하는지입니다. 모든 단계는 비워 둘 수 있고, 설정한 내용은 나중에 **설정**에서 모두 바꿀 수 있습니다.

![AI 단계: 이 컴퓨터에서 찾아 테스트한 구독 CLI](../../screenshots/onboarding-ai.webp)

## 환영 화면

단계 전에 환영 화면에서 다른 컴퓨터의 **설정 파일 가져오기**를 제안합니다. 키와 토큰이 든 파일은 유지 상자를 체크하지 않으면 그것들이 제거되고, 암호로 보호된 내보내기는 그 자리에서 암호를 묻습니다. 가져오면 파일이 적용되고 마법사가 닫힙니다 — 내보내기에 무엇이 들어 있는지는 [보안과 비밀](security.md)을 보세요.

## 단계

왼쪽 열에 단계가 나열됩니다. 초록 체크는 입력한 단계, 대시는 입력 없이 지나간 단계, 강조된 행은 현재 단계입니다.

| 단계 | 설정하는 것 | 나중에 바꾸는 곳 |
|---|---|---|
| Git 신원 | 프로필 이름과 커밋의 이름·이메일 | 설정 → 프로필 |
| 계정 | GitHub, GitLab, Azure DevOps, Bitbucket, Forgejo, 자체 호스팅 서버의 토큰과 **다른 앱으로 열기…** 앱 | 설정 → 연동, 앱은 설정 → 일반 |
| 인공지능 | 사용 중으로 지정된 AI 계정 하나 | 설정 → AI |
| 모양 | 테마와 밝게·어둡게·자동 모드 | 설정 → 테마 |
| 완료 | 새 설정 없음 — 설정된 내용 요약 | — |

**지금은 건너뛰기**는 어느 단계에서든 마법사를 닫고 입력한 내용을 유지합니다.

## AI 단계

AI는 선택 사항입니다. 세 카드 중 하나를 고르거나 **건너뛰기, AI 없음**을 누르세요:

| 카드 | 사용하는 것 | 필요한 것 |
|---|---|---|
| 내 구독 | 요금제로 로그인한 Claude Code 또는 Codex | 설치되고 로그인된 CLI |
| API 키 | OpenAI, Anthropic, Gemini, Groq, OpenRouter, Mistral | 제공자의 키 |
| 내 컴퓨터에서 | 로컬에서 실행되는 Ollama 또는 LM Studio — 아무것도 밖으로 나가지 않음 | 실행 중인 서버 |

이 컴퓨터에서 Claude Code나 Codex를 찾으면 구독 카드가 어느 것인지와 버전을 알려 주고, 카드를 고르면 테스트합니다. 짧은 프롬프트 하나를 보낸 뒤 **테스트 완료: N초 만에 응답. 바로 사용할 수 있습니다.**가 표시됩니다. 아무것도 없거나 CLI가 로그인되어 있지 않으면 카드에 [설정 → AI](ai.md)와 같은 연결 설정이 나타납니다.

API 키나 로컬 서버는 **계속**이 제공자의 모델 목록을 가져와 연결을 테스트하고, 응답한 계정만 저장합니다.

이 단계가 저장하는 것은 설정과 같은 방식으로 기록되고 **사용 중**으로 지정된 일반 AI 계정입니다. 설정 → AI를 열면 거기 있으며, 이름 바꾸기, 일부 기능에만 쓰기, 삭제가 가능합니다. 여러 계정, 기능별 모델, AI의 작성 방식은 마법사가 아니라 그곳에서 설정합니다.

## 제한

- **구독 테스트는 프롬프트 하나만큼 사용합니다.** 다른 요청처럼 요금제 사용량에 포함됩니다. 카드를 고르거나 **다시 테스트**를 누를 때만 실행됩니다.
- **Claude Code와 Codex만 감지합니다.** Gemini CLI와 Devin은 설정 → AI에서 추가하는 일반 CLI 계정으로 응답합니다.
- **로컬 서버는 이미 실행 중이어야 합니다.** 마법사는 Ollama나 LM Studio를 시작하지 않고 모델도 내려받지 않습니다.
- **마법사는 한 번만 실행됩니다.** 닫힌 뒤 설정한 모든 것은 설정에 있으며, 마법사를 다시 열 방법은 없습니다.
