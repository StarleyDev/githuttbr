# 테마와 겉모습

기본 제공 테마 — GitHuttBr, Nord, Dracula, Solarized, GitHub, Monokai,
Midnight, Contrast, Daltonic — 각각 밝은 변형과 어두운 변형이 있어요.

![밝은 모드에서 어두운 모드로 전환하기](../../screenshots/clip-themes.webp)

- **밝게, 어둡게, 또는 OS를 따라가기**. 실시간으로 전환돼요.
- **직접 만든 테마**, 그리고 프롬프트로 **AI가 생성한** 테마.
- 조절 가능한 **코드 글꼴 크기**.
- 도구 모음과 사이드바 구역의 **아이콘 색상** — 아래를 보세요.
- **그래프의 모양** — 레인 팔레트, 모서리, 행 밀도, 선 굵기와 실시간 미리 보기 — 은 전용 페이지 **설정 → 그래프**에 있습니다. [커밋 그래프](graph.md)를 보세요.

![테마 설정](../../screenshots/settings-themes.webp)

## 아이콘 색상

회색 아이콘이 한 줄로 늘어서 있으면 가져오기, 푸시, 스태시는 이름을 읽기 전까지
비슷해 보입니다. 테마 탭의 모양 아래에 있는 **아이콘 색상**은 각 아이콘을 하는 일에
따라 색칠해서, 눈이 글자보다 먼저 동작을 찾게 합니다.

| 역할 | 아이콘 | 쓰는 테마 색 |
|---|---|---|
| 받기 | 가져오기, 풀, 원격, 워크트리 | 테마의 청록(cyan) 슬롯 |
| 보내기, 마무리 | 푸시, 할 일, 이슈, 릴리스 | 초록 |
| 참조 | 브랜치, 로컬, 태그, 풀 리퀘스트, 마일스톤, 서브모듈 | 강조색 |
| 따로 두기 | 스태시, 팝, 스태시 목록, 북마크, 고정됨 | 테마의 주황 슬롯 |

실행 취소, 다시 실행, 도구, 설정은 회색으로 남습니다. 보조 기능이고, 이것들을
수수하게 두어야 색이 있는 것들이 눈에 띕니다.

항목이 많은 목록은 그룹 전체를 한 번에 색칠해서, 한 그룹이 한 가족처럼
읽히게 합니다.

- **도구 메뉴** — 시간 여행(Reflog, 작업 중 스냅샷, 타임머신, Bisect)은 주황,
  브랜치 도구(흡수, 레이더들, 로컬 CI, 비교)는 강조색, 그리고 그룹마다 한 가지 색:
  살펴보기는 청록, 브랜치와 히스토리는 강조색, 파일과 패치는 초록, 저장소는 주황,
  비밀과 공유는 빨강.
- **설정 페이지** — 레이아웃 및 터미널, 워크스페이스, AI는 강조색, 프로필 및 신원, 코드 분석기, 환경는 초록, 연결된 계정, Git 및 동기화, 데이터 및 백업는 청록, 테마와 그래프는 주황, 보안 및 확인는 빨강입니다. 일반, 단축키, 정보는 회색으로 남습니다.

레이블 없는 아이콘 버튼 줄은 반대로 합니다 — 서로 구별되도록 버튼마다 고유한 색이
붙습니다. [풀 리퀘스트 페이지](pull-requests.md)의 머리글 버튼은 새로 고침이 파랑, AI
리뷰가 강조색, 로컬에서 미리보기가 청록, 소스 브랜치로 이동이 초록, 대상 브랜치로
이동이 주황(브라우저에서 열기는 회색 그대로)이며, 내 댓글의 **편집**은 강조색,
**삭제**는 빨강을 띱니다 — 그곳과 이슈 페이지 모두에서. 파랑과 청록은 테마 색을 섞은
것이라 이 역시 테마를 따릅니다.

| 옵션 | 보이는 모습 |
|---|---|
| **단색** | 모든 아이콘이 회색. 이 옵션이 생기기 전과 같습니다 |
| **부드러운 색조** (기본값) | 회색에 섞인 색. 마우스를 올리면 온전한 색 |
| **선명한 색상** | 색 그대로, 같은 색조의 작은 칩 위에 |

색은 테마에서 옵니다. 초록이나 강조색을 바꾸는 테마는 아이콘도 함께 바꿉니다.
직접 만든 테마와 AI가 생성한 테마도 마찬가지입니다.

한계: 색이 입혀지는 곳은 도구 모음의 주요 버튼, 사이드바 구역 머리글, 도구 메뉴,
커밋, 브랜치, 저장소의 오른쪽 클릭 메뉴, 설정 페이지, 그리고 풀 리퀘스트와 이슈 페이지의 버튼뿐입니다. 다른 메뉴, 구역 안의
행, 커밋 그래프에는 입혀지지 않습니다. 마우스를 올린 메뉴 행은 아이콘까지 평소 모습을
유지합니다. 색이 유일한 단서가 되는 일은 없습니다 — 모든 아이콘은 이름을 그대로
유지합니다.

## 설정의 구성

사이드 메뉴는 페이지를 주제별로 묶습니다.

| 그룹 | 페이지 |
|---|---|
| **나** | 프로필 및 신원 · 연결된 계정 · AI — 앞의 두 페이지는 제목에 표시된 프로필을 편집합니다([프로필](profiles.md)) |
| **모양** | 테마 · 그래프 · 레이아웃 및 터미널 |
| **동작** | 일반 · Git 및 동기화 · 보안 및 확인 · 코드 분석기 |
| **시스템** | 워크스페이스 · 단축키 · 환경 · 데이터 및 백업 · 정보 |

일반에는 앱 전체에 관한 것만 남았습니다 — 언어, 저장소 탭 표시, 데스크톱 알림, 업데이트 후 체인지로그 열기, 닫을 때 경고. 나머지는 알맞은 페이지로 옮겨졌고, 페이지의 안내 문구가 그곳으로 연결합니다.

| 옵션 | 현재 위치 |
|---|---|
| 처음 불러올 커밋 수, “더 불러오기” 한 번당 커밋 수, 스크롤하면 자동으로 더 불러오기, 상대 날짜, 아바타 표시, GitHub 프로필 사진 사용 | **그래프** — 테마의 그래프 탭에 있던 레인 팔레트, 선 모서리, 행 밀도, 노드 스타일, 그래프 포커스, 스태시 배치, 선 두께와 함께 |
| 자동 페치 주기 (분), 항상 머지 커밋 만들기, 충돌 해결 기억하기, 외부 diff 및 머지 도구, 외부 편집기, 기본 “다음으로 열기” 앱 | **Git 및 동기화** |
| 강제 푸시 전에 확인 | **보안 및 확인** |
| 코드 분석기, launch.json | **코드 분석기** |
| 파일 뷰어, 프로필 아바타 애니메이션, 완료한 할 일 숨기기, 접두사로 ref 묶기 | **레이아웃 및 터미널** |

연동는 이제 **연결된 계정**, 데이터는 **데이터 및 백업**입니다. 각 옵션이 하는 일은 바뀌지 않았고 저장된 설정도 그대로 이어집니다. 예전 이름으로 페이지를 여는 링크도 올바른 페이지로 갑니다.

## 설정 찾기

설정은 여러 페이지로 나뉘어 있고, 원하는 옵션은 짐작한 곳에 있는 경우가 드물어요.
있다는 건 알아도 어느 페이지에 있는지는 모르니까요. 설정 헤더의 닫기 버튼 옆에
있는 검색 창은 모든 페이지를 한꺼번에 찾아봐요.

![설정에서 “terminal” 검색](../../screenshots/settings-search.webp)

입력하는 동안 오른쪽에 일치하는 설정이 페이지별로 묶여 나타나요. 각 항목에는 이름,
한 줄 설명, 그리고 그 설정이 있는 페이지가 표시돼요. 사이드바는 일치하는 항목이
없는 페이지를 흐리게 하고, 있는 페이지에는 개수를 보여 줘요.

- 설정의 이름, 설명, 페이지 이름을 비교합니다 — 메뉴가 다시 묶이기 전에 있던 페이지 이름도 포함되므로 "general fetch"로도 Git 및 동기화의 자동 fetch를, "integrations"로 연결된 계정를 찾을 수 있습니다. 대소문자와 악센트는 무시하며, 입력한 모든 단어가 들어 있어야 하므로 "terminal font"는 터미널 글꼴 설정으로 좁혀집니다.
- 인터페이스 언어와 영어로 동시에 찾아요. 앱을 한국어로 쓰고 있어도 "token"이나
  "font"를 입력하면 해당 설정을 찾을 수 있어요.
- 결과를 클릭하거나 **Enter**로 첫 결과를 고르면 그 페이지를 열고 설정까지 스크롤한 뒤 잠깐 강조합니다.
- **Esc**는 검색을 지우고, **Esc**를 한 번 더 누르면 설정이 닫혀요.

검색 대상은 이름과 설명이고, 직접 지정한 값은 아니에요. 연동에 있는 호스트별 서버
목록(GitHub Enterprise Server, 자체 관리형 GitLab, Bitbucket Data Center)은
연동 페이지를 여는 데까지만 하고, 호스트 탭은 직접 골라야 해요. 개별 키보드 단축키는
색인되지 않아요. 검색은 단축키 페이지를 찾아 주고, 그 페이지의 편집기에 목록이
있어요.

## 배치

사이드바는 왼쪽이나 오른쪽에, 어디서나 크기를 조절할 수 있는 패널, 그래프가 창
전체를 차지할 만할 때를 위한 접히는 사이드바, 그리고 저장소별 터미널 배치.

같은 페이지 **설정 → 레이아웃 및 터미널**에는 제목 표시줄과 사이드바의 추가 항목 — **프로필 아바타 애니메이션**, **완료한 할 일 숨기기**, **접두사로 ref 묶기** — 과 파일 뷰어의 변경 표시줄, 미니맵도 있습니다.
