# 보안과 비밀

Gitcito에는 **백엔드가 없어요**. 네트워크 호출은 Git 호스트로, 그리고 켜 두었다면
AI 공급자로 나가는 것이 전부예요.

![보안 설정](../../screenshots/settings-security.webp)

## 비밀 마스킹

`.env*`, `*.pem`, `*.key`, `id_rsa`, `credentials.*` 같은 파일의 값은 diff, 파일,
blame 화면에서 `KEY=••••••` 로 표시돼요. 화면 공유나 스크린샷으로 값이 새어 나갈
수 없도록요.
Apple 서명 자료도 포함됩니다: `*.mobileprovision`, `*.provisionprofile`,
`*.p12`, 그리고 App Store Connect의 `*.p8` 키. `*.cer`는 아닙니다 — 인증서는
원래 공개되는 것이니까요.

이건 **표시 전용**이에요. 파일을 바꾸지 않고, 무엇을 스테이징할지도 바꾸지
않아요. 눈 모양 토글로 화면별로 값을 드러낼 수 있어요. `.env.example`, `.sample`,
`.template` 은 비밀이 아니라 템플릿으로 취급해요.

![모든 값이 마스킹된 .env 파일과 값을 드러내는 토글](../../screenshots/secret-masking.webp)

## 사고가 나기 전에 막는 가드

| 가드 | 언제 |
|---|---|
| **비밀 파일** | 자격 증명처럼 보이는 것을 커밋할 때 — 클릭 한 번으로 *무시하고 추적 해제* 가능 |
| **대용량 파일** | 지나치게 큰 blob 을 커밋할 때 (기준값은 설정 → 보안) |
| **빌드 찌꺼기** | `xcuserdata/`, `DerivedData/`, `.DS_Store`를 커밋할 때 — 같은 원클릭 *무시하고 추적 해제* 제공 |
| **보호된 브랜치** | `main`/`master` 에 바로 커밋하거나 강제 푸시할 때 |
| **추적 중인 비밀** | 비밀 파일을 *추적하는* 저장소를 푸시할 때 — 세션당 한 번 경고 |

## OS 키체인

토큰과 [금고](vault.md) 항목은 설정 파일에 든 키가 아니라 OS 키체인(Electron
`safeStorage`)으로 암호화돼요.

**당신이 허락하기 전에는 키체인에 아무것도 닿지 않아요.** 시스템 자체의 권한
대화 상자가 뜨기 전에, Gitcito가 무엇이 저장되는지, 무엇은 할 수 없는지(앱은
자기가 만든 항목만 다시 읽을 수 있어요 — 당신의 다른 비밀번호에는 손이 닿지
않아요), 그리고 거절해도 괜찮다는 사실을 설명해요. 거절하면 토큰은 그 세션
동안만 메모리에 머물고, 금고는 닫힌 채로 있으며, 나중에 **설정 → 보안 → OS
키체인**에서 켤 수 있어요.

새로 설치한 직후에는 실제로 저장할 것이 생기기 전까지 키체인 호출이 **하나도**
일어나지 않아요.

꺼져 있는 동안에는 연동의 토큰 칸에 그 사실이 표시됩니다 — *Gitcito를 종료할 때까지만 보관됩니다: 시스템 키체인이 꺼져 있습니다.* — 옆에 **사용** 버튼이 있습니다. 거기서든 여기서든 켜면 이번 세션에 이미 입력한 토큰도 저장되므로 다시 붙여 넣을 필요가 없습니다.

### 키링이 없는 Linux

Linux 에서 키체인은 시크릿 서비스 — GNOME Keyring 또는 KWallet — 예요. 아무것도
실행 중이지 않으면 시스템은 여전히 "암호화"하지만, 모든 기기에서 똑같은 고정
비밀번호로 해요. 토큰과 키는 뒤섞일 뿐 보호되지 않아요. 설정 → 보안 은 키체인
상태 아래에 이를 알려요 — *실행 중인 키링(GNOME Keyring 또는 KWallet)이 없어…* —
*키체인* 이라는 말이 없는 보호를 뜻하는 일이 없도록요.

누구나 풀 수 있는 저장소에 새로운 것이 들어가지 않도록, 키링이 실행 중이지 않을
때 입력한 토큰은 **앱을 종료할 때까지만** 보관돼요. 토큰 입력란도 그렇게
알려요 — *Gitcito를 종료할 때까지만 보관됩니다: 실행 중인 키링이 없고…* — 다시
시도 버튼은 없어요. 다시 시도해도 소용없고, 키링만이 해결할 수 있으니까요. 전에
저장한 토큰은 계속 읽을 수 있고 — 접근이 막히는 일은 없어요 — 토큰을 지우거나
바꾸면 예전 값은 여전히 디스크에서 삭제돼요. 한계가 두 가지 있어요. 공통 AI 의
키는 공유 자리로 옮겨지지 않고(각 프로필은 계속 자기 키를 읽어요), 금고는 세션
전용 모드가 없어서 계속 기본 저장소에 저장해요. 새 토큰을 다시 저장하려면 키링을
설치하거나 잠금을 풀고 Gitcito 를 다시 시작하세요.

## 설정 가져오기

**설정 → 가져오기 / 내보내기** 로 설정, 프로필, 테마를 기기 사이에 옮길 수
있어요. 기본 내보내기에는 **토큰도 API 키도 들어가지 않고**, 그런 파일을
가져와도 저장해 둔 것은 전혀 건드리지 않아요 — 파일 속 빈 토큰은 "이 파일에는
없음"이라는 뜻이지, "내 것을 지워라"가 아니에요.

### 가져올 항목 고르기

설정 파일에는 두 종류가 들어 있어요. *당신* 을 따라다니는 것(프로필, 테마,
단축키)과, 그 파일을 만든 기기에서만 의미가 있는 것(저장소가 있는 폴더, 터미널
경로)이에요. 새 컴퓨터에서 전부 적용하면 사이드바가 아무 데도 가리키지 않는 탭으로
가득 차요. 그래서 파일을 고르고(비밀번호가 있으면 입력하고) 나면, 어느 항목을
가져올지 대화 상자가 물어요. **가져오기** 를 누르기 전에는 아무것도 적용되지
않고, **취소** 하면 모두 그대로예요.

![설정 → 데이터 → 가져오기: 네 항목, 폴더가 여기에 하나도 없어서 체크가 해제된 저장소, 그리고 열려 있는 경로 변환](../../screenshots/settings-import.webp)

| 항목 | 담긴 것 |
|------|-----------------|
| **프로필과 계정** | 프로필, Git 신원, 연동 링크, 공통 AI 설정과 프로필 이미지 — 파일에 있으면 자격 증명과 [금고](vault.md)도 |
| **앱 환경설정** | 테마, 언어, 단축키, 레이아웃, 그래프와 아이콘 색 |
| **저장소와 작업 공간** | 탭, 작업 공간, 즐겨찾기, 별칭, 탭 그림, 저장소마다 쓰는 프로필, 검색하는 폴더, 그리고 저장소별 메모와 위키 |
| **이 컴퓨터의 프로그램** | 터미널, 외부 편집기, 기본 앱, AI CLI 경로 |

항목마다 파일에 그 항목의 내용이 몇 개 들어 있는지 보여 줘요. 체크하지 않은 항목은
이 기기에서 그대로 남아요.

**프로필은 내 것과 병합돼요.** 다른 컴퓨터에서 온 파일에 이 컴퓨터의 프로필이
모두 있는 경우는 드물어요 — Linux 노트북에서 추가한 계정, Mac 에만 있는 고객용
프로필처럼요. 그래서 **프로필과 계정** 은 목록을 바꾸는 대신 파일의 프로필을 내
것에 더해요. 가져오기 전에 이 항목은 프로필마다 어떻게 되는지 보여 줘요.

| 태그 | 뜻 |
|-----|---------|
| **업데이트** | 양쪽에 다 있는 프로필: 파일의 신원, AI, 이미지가 내 것을 대신하고, 서버는 내 것에 더해져요 |
| **새 프로필** | 파일에만 있음: 내 것 뒤에 추가돼요 |
| **유지** | 이 컴퓨터에만 있음: 그대로 남아요 |

두 프로필은 id 가 같으면 "같은 것"이에요 — 모든 설치의 첫 프로필이 그래요. 맞는
id 가 없으면 이름으로 맞추고(대소문자와 앞뒤 공백은 무시), 프로필은 **이
컴퓨터의 id** 를 유지해요. 거기에 연결된 저장소, 활성 프로필, 저장된 자격 증명과
이미지가 그대로 붙어 있어요. 어느 프로필이 활성인지는 바뀌지 않아요.

**모두 바꾸기** 도 여전히 있어요. 백업을 원래 모습 그대로 되돌리고 싶을 때를
위해서요. 파일의 프로필만 남고, 이 컴퓨터에만 있는 프로필은 취소선과 함께
**제거됨** 으로 표시돼요. 그러면 **가져오기** 를 누를 때 그 이름들을 알리며 한 번
더 물어요 — 저장된 자격 증명과 이미지까지 함께 사라지고, 되돌릴 수 없어요. **모두
바꾸기** 에서는 파일의 활성 프로필이 활성 프로필이 돼요.

한계: 맞추기는 id 나 정확한 이름으로만 해요 — 한쪽에서 이름을 바꾼 프로필은 새
것으로 취급되어, 둘 다 남게 돼요. 맞춰진 프로필은 파일의 값을 받지만, 이 컴퓨터에만
있는 것을 잃지 않도록 예외가 세 가지 있어요. GitHub Enterprise, GitLab, Bitbucket
서버는 내 것에 **더해져요**(양쪽에 있는 서버는 파일의 항목이 이겨요). 파일에서
비어 있는 토큰은 내 것을 유지해요 — 단 같은 인스턴스일 때만이라, 토큰이 다른
Forgejo, 다른 GitLab 발급자, 다른 Azure 조직으로 보내지는 일은 없어요. 그리고 이
기기의 자격 증명 도우미에서 빌려 온 로그인은 이 기기의 것으로 남아요.

**기본 체크는 디스크를 보고 한 추측이에요.** 대화 상자를 보여 주기 전에 Gitcito
는 파일의 저장소 폴더가 여기에 있는지 확인해요. 하나도 없으면 파일은 다른
컴퓨터에서 온 거예요. **저장소** 와 **프로그램** 은 이유와 함께 체크 해제된 채로
시작해요 — 프로그램 경로가 나열되니, 다른 곳의 것임을 알 수 있어요. 폴더가
있으면 같은 컴퓨터(예를 들어 복원한 백업)라서 모두 체크된 채로 시작하고, 초록색
메모가 그렇게 알려요. 저장소가 하나도 없는 파일은 대신 프로그램 경로로 판단해요.
**프로그램** 은 그 경로가 모두 여기에 있을 때만 체크된 채로 시작해요.

확인 자체가 실패하면 아무것도 추측하지 않아요. **저장소** 와 **프로그램** 은 판정
없이 체크 해제된 채로 시작하고, **다시 확인** 버튼으로 디스크에 한 번 더 묻고,
확인이 성공하기 전까지 **저장소** 는 가져올 수 없어요. 다른 항목은 가져올 수
있어요.

**경로 변환.** 폴더가 없는 파일에서 **저장소** 에 체크하면 **경로 변환** 상자가
열려요. 왼쪽은 파일의 저장소들이 공통으로 가진 폴더(`/home/you/code`), 오른쪽은
그 폴더가 이 컴퓨터의 어디에 있는지로, 홈 폴더를 바탕으로 미리 채워져
있어요(`/Users/you/code`). 둘 다 고칠 수 있어요 — 추측이 틀릴 수 있고, 공통
폴더를 찾지 못하면 Gitcito 는 둘 다 비워 두고 입력을 기다려요. 입력하는 동안
막대가 이제 여기에 폴더가 있는 저장소 수를 세고 그중 몇 개를 보여 줘요 — 찾은
것은 초록, 아직 없는 것은 빨강이에요. 바꿀 때 저장소의 별칭, 탭 그림, 프로필,
그리고 메모, 위키, 금고 항목도 함께 따라가니, 손으로 다시 설정할 것이 없어요.

아래쪽이 요약해 줘요 — *4개 항목 중 3개를 가져옵니다 · 폴더 31개* (검색 루트와
마지막 클론 폴더도 세기 때문에 저장소가 아니라 폴더라고 해요) — 그리고 항목이
적어도 하나 체크될 때까지 **가져오기** 는 꺼져 있어요.

**변환으로 아무것도 찾지 못해도 가져오기는 꺼져 있어요.** **저장소** 에 체크했는데
새 접두사 아래에서 폴더를 하나도 찾지 못했다면, 가져오기는 저장소를 비워 버릴
거예요. 경로를 고치거나 그 항목의 체크를 해제하세요.

변환의 한계:

- **접두사 하나를 다른 접두사로 바꾸는 것**이에요. 파일에서 다른 폴더 아래에
  있거나 여기서는 다르게 배치된 저장소는 찾지 못해요. 저장소별 매핑은 없어요.
- 변환이 적용되면 **그 결과 폴더가 있는 저장소만 가져와요**. 나머지는 빠지고 —
  깨진 탭으로 추가되지 않고 — 대화 상자가 몇 개인지 알려 줘요.
- 프로그램은 절대 변환하지 않아요. `/usr/bin/code` 는 다른 시스템에서 믿을 만한
  짝이 없으니까요. 그 항목은 체크 해제한 채로 두고 설정에서 고르세요.
- 어느 쪽 접두사든 비우면 경로를 파일에 있는 그대로 가져와요.

**가져오는 동안** 에는 대화 상자를 닫을 수 없어요. 뒤의 단계 — 저장소 메모, 금고,
프로필 이미지 — 가 실패하면 대화 상자는 열린 채로 그 단계를 알려 주고, **가져오기
계속** 으로 앞 단계를 다시 쓰지 않고 거기서부터 이어 가요.

### 파일 속 자격 증명

옵션에 체크하고 내보낸 파일에는 자격 증명이 들어 있어요. 프로필을 병합할 때는 늘
자격 증명을 **더해요**. 파일의 것은 맞는 프로필 아래에 저장되어 같은 계정의 것을
대신하고, 나머지 저장된 자격 증명은 모두 남아요 — 지우면 프로필을 유지하는 것과
모순되니까요. 프로필이 **모두 바꾸기** 일 때는, 그런 파일에서 **프로필과 계정**
바로 아래에 선택지도 나와요.

| 선택 | 저장된 내 자격 증명 |
|--------|------------------------|
| **내 것에 추가** | 파일의 것이 더해지고 같은 계정의 것은 대신해요. 나머지는 모두 유지돼요 |
| **모두 바꾸기** | 파일의 것과 똑같아져요 — 파일에 없는 저장된 토큰과 API 키는 모두 삭제돼요 |

이 선택은 프로필과 함께 적용돼요. **프로필과 계정** 의 체크를 해제하면 자격 증명은
하나도 가져오거나 지우지 않아요. 옵션 없이 내보낸 파일은 무엇에 체크하든 내놓을
자격 증명이 없어요. **모두 바꾸기** 는 **가져오기** 를 누를 때 한 번 더 물으며, 파일에
없는 저장된 토큰과 API 키가 모두 삭제된다고 알려요. 거기서 **취소** 하면 대화
상자는 그대로예요.

**모두 바꾸기에는 키체인이 필요해요.** 키체인이 꺼져 있거나 쓸 수 없으면 예전
토큰이 암호화된 저장소에 남아 다음 실행 때 돌아오므로, Gitcito 는 거부해요. 그렇게
알리고 아무것도 가져오지 않아요. 저장된 토큰을 읽을 수 없는 동안에도 마찬가지예요.
읽을 수 있게 되는 순간 돌아올 테니까요. **내 것에 추가** 는 계속 되고, 파일의
토큰을 세션 동안 보관해요.

**한계:** 자격 증명은 프로필에 속해요. 가져오기가 제거하는 프로필은 무엇을
고르든 저장된 토큰을 함께 가져가요.
