# 프로필

프로필은 **Git 신원**(이름과 이메일)을 그에 딸린 **연동 토큰**과 함께 묶어요.
프로필을 전환하면 둘이 같이 바뀌어요 — 커밋은 올바른 작성자로 기록되고 API 호출은
맞는 계정을 써요.

한 컴퓨터로 업무용 저장소와 개인 저장소를 모두 다루거나, GitHub 계정이 두 개일 때
유용해요.

## 프로필 편집하기, 프로필 사용하기

설정에서 두 페이지가 프로필에 따라 달라집니다 — **프로필 및 신원**과 **연결된 계정**로, 제목에 편집 중인 프로필 이름이 나오는 **나** 그룹의 맨 위에 있습니다. 다른 페이지는 모두 어느 프로필에서나 똑같이 적용되며 맨 위에 그렇게 표시합니다.

**프로필 및 신원**은 프로필 카드로 시작합니다. 사진, 이름(그 자리에서 편집), 앱이 사용 중이면 *사용 중*, 선택기, **새 프로필**. **연결된 계정**는 같은 선택기를 *편집 중인 프로필* 막대로 보여 주며 시작합니다. 선택기는 **편집할** 프로필을 고를 뿐, 앱이 **사용하는** 프로필은 바꾸지 않습니다. 둘이 다르면 호박색 띠가 알려 주고 **이 프로필 사용**로 바꿀 수 있습니다. 계정을 엉뚱한 프로필에 연결하기 가장 쉬운 순간이라, 연결된 계정는 카드마다, 그리고 버튼 자체에도 프로필 이름을 표시하며 확인 창도 이를 반복합니다. 프로필 삭제도 같은 곳에 있고 먼저 묻습니다.

카드 아래에는 git 신원과 커밋 서명이 있습니다. 열린 저장소가 다른 사람으로 커밋하는 경우 — git 설정이 다른 작성자를 가리키는 경우 — 그렇다는 줄과 **현재 저장소에 신원 적용**가 나타납니다. 둘이 같으면 적용할 것이 없어 줄이 나오지 않습니다. 이어서 프로필 사진, **연결된 계정** 요약 — 호스트마다 *연결됨*, *토큰 만료 또는 오류*, *연결할 수 없음*, *연결 안 됨* 중 하나와, 그 호스트로 연결된 계정를 여는 **연결** 또는 **갱신** — 그리고 프로필이 쓰는 AI가 나옵니다.

요약은 페이지를 열 때마다, 토큰이 바뀔 때마다 로그인 창 없이 조용히 확인하며, 주기적으로 묻지 않습니다. 찾은 결과는 사이드 메뉴도 씁니다. 토큰이 거부되거나 확인에 실패하면 **연결된 계정**에 작은 경고 숫자가 붙습니다 — 설정이 이미 한 확인에 대해서만입니다. 연결할 수 없는 호스트는 세지 않습니다. 토큰은 괜찮을 수 있으니까요.

## AI는 공유됩니다

프로필마다 별도 AI가 필요하지는 않습니다. 하나의 [공통
AI](ai.md#모든-프로필에-하나의-ai)가 모든 프로필을 맡고, 프로필은 꼭
필요할 때만 별도 AI를 씁니다. 이 선택은 모든 것에 적용됩니다: 공통 AI를 쓰는
프로필은 쓰는 방식도 공통 AI의 설정을 따릅니다 — 커밋 스타일, 커밋용 추가 규칙,
저장소 채팅. 다른 스타일이 필요한 프로필은 별도 AI를 받습니다. 공통 AI의
복사본이라 나중에 바꿀 수 있습니다. 모두 **AI** 페이지에서 편집하며, 프로필
페이지는 그 프로필이 어떤 AI를 쓰는지만 알려 주고 그곳으로 연결합니다.

## 프로필마다 자기 계정

프로필은 토큰 외에도, 컴퓨터에 이미 있는 로그인(git의 credential helper나
GitHub CLI)을 설정 → 연결된 계정에서 **연결**할 수 있습니다. 연결은 한 프로필에만
속합니다. 새 프로필은 연결되지 않은 상태로 시작하고, 다른 프로필이 이미 가진
계정은 거부되므로, 두 프로필이 두 GitHub(또는 Azure DevOps) 계정을 나란히 가질
수 있습니다. [호스팅](hosting.md)을 참고하세요.

## 저장소별 연결

저장소를 **프로필에 연결**해 두면, 다른 프로필에 속한 저장소를 보고 있는 동안에도 그
저장소에 대한 백그라운드 페치가 항상 올바른 계정으로 인증해요.

토큰은 설정 파일이 아니라 [OS 키체인](security.md)에 저장돼요.
