# はじめの一歩

Gitcito はフォルダを開き、その履歴を見せます。あなたが頼むまで、リポジトリには
何も書き込みません。

![開いたばかりの、まだコミットのないリポジトリ](../../screenshots/empty-repo.webp)

## リポジトリを開く

![リポジトリを開く：開く・クローン・作成、その下にスキャンしたリポジトリと最近のリポジトリ](../../screenshots/open-repository.webp)

- **フォルダをウィンドウにドラッグ** するか、ようこそ画面の **リポジトリを開く** を
  使います。選択ダイアログでは複数のフォルダを一度に選べます。⌘-クリックか
  Shift-クリックで選ぶと、それぞれが自分のタブで開きます（グループから開いた場合は
  そのグループに加わります）。複数を選んだとき、すでに開いているリポジトリや
  Git リポジトリではないフォルダは飛ばされ、メッセージで名前が示されるので、ほかは
  そのまま開きます。macOS の選択ダイアログでは、開いているリポジトリを前もって
  グレー表示にできません。Electron がパネルのフォルダごとのフックを公開していない
  ため、確認は「開く」をクリックしたあとに行われます。
- 3 つのボタンの下にある **スキャンしたリポジトリ** には、Gitcito にスキャンを
  任せたフォルダ内のリポジトリがすべて並びます。いくつかにチェックを入れてまとめて
  開くか、ひとつをダブルクリックします。そのフォルダの追加や削除もここで行います。
  [リポジトリ](repositories.md#スキャンしたリポジトリ) を参照してください。
- **押し間違えたら？** リポジトリを開く から開いたクローン、作成、グループを作成、
  スキャンしたリポジトリには、タイトルの横にそこへ戻る **戻る** 矢印があります。
- URL から、あるいはホストから直接 **クローン** します。巨大なリポジトリを素早く
  クローンするための選択肢は [クローン](cloning.md) にまとめてあります。
- ターミナルからは `gitcito .` で、実行中のアプリに現在のフォルダが開きます —
  [コマンドライン](cli.md) を参照してください。
- まだ Git リポジトリではないフォルダも、1 つだけなら開けます。その場合は初期化を
  提案します。

## 3 つのペイン

| ペイン | 中身 |
|---|---|
| 左 | ブランチ、リモート、タグ、スタッシュ、ワークツリー — そして作業ツリーのための **ファイル** タブ |
| 中央 | コミットグラフと、そこから選んだもの |
| 右 | コミットの作成欄、または選択したコミットの詳細 |

## それ以外を見つける

道は 2 つあり、どちらも同じ場所に着きます。

- **`⌘K`**（`Ctrl+K`）— コマンドパレット。欲しいものを打つだけです。ブランチ、
  コミット、ファイルへの移動にも使えます。
- ツールバーの **ツール** — 同じリポジトリ向けの一式をメニューにしたもので、
  数の多い後半はグループに畳んで読めるようにしてあります。

![ツールメニュー。よく使うものが先で、残りはグループにまとめられている](../../screenshots/tools-menu.webp)

ウィンドウが狭くなると、アクションバーは場所を奪い合うのをやめます。収まらなくなったボタンは、並び順とサブメニューをそのままに、末尾の **その他** メニューへ折りたたまれます。ウィンドウを広げれば元に戻ります。

片方から辿り着けるものは、もう片方からも辿り着けます。上級者だけが見つけられる機能は
ありません。

## 最初のコミット

1. ファイルを編集します。**未ステージ** に現れます。
2. ステージします — ファイル全体でも、ハンク単位でも、[1 行ずつ](staging.md) でも。
3. メッセージを書いて **コミット** を押します。

Gitcito のそれ以外はすべて任意です。
