# コメントを書く

GitHub に送るコメントは Markdown です。素のテキスト欄では `**` や `- [ ]` を
すべて手で打ち、表が正しく表示されたかをブラウザーで確かめるしかありません。
ホストに書き込むアプリ内のすべての入力欄が、いまは同じエディターになり、GitHub
自身のコメント欄と同じツールを備えています。

- プルリクエストのコメント欄、スレッドの返信、行コメント
  （[プルリクエストページ](pull-requests.md)）
- イシューのコメント欄
- 新しいプルリクエストの説明と、新しいイシューの本文
  （[ホスティングとプルリクエスト](hosting.md)）

![プルリクエストのコメント欄。書式ツールバーと、「@al」で開いたメンション候補の一覧](../../screenshots/comment-editor.webp)

## 書くとプレビュー

**プレビュー** は、アプリのほかの部分と同じ Markdown レンダラーで、表示される
とおりにテキストを描きます。読み取り専用です。**書く** に戻ると、テキストと
カーソルは離れたときの位置のままなので、⌘/Ctrl+Z で見る前に打った内容をまだ
元に戻せます。

タブはタブリストです。どちらかにフォーカスがあるとき、← と → で切り替えます。

## ツールバー

| ツール | ショートカット | 動作 |
|---|---|---|
| **見出し** | — | 選択した行に H1・H2・H3 を付けるメニュー。行がすでに持つレベルを選ぶと外れます |
| **太字** | ⌘/Ctrl+B | `**テキスト**` |
| **斜体** | ⌘/Ctrl+I | `_テキスト_` |
| **コード** | ⌘/Ctrl+E | 行内なら `` `コード` ``、選択が複数行にわたれば ```` ``` ```` で囲んだブロック |
| **リンク** | ⌘/Ctrl+K | `[テキスト](url)` — 選択した URL はアドレスに、それ以外のテキストはラベルになります |
| **引用** | — | 選択した各行に `> ` |
| **箇条書きリスト** | ⌘/Ctrl+Shift+8 | 選択した各行に `- ` |
| **番号付きリスト** | ⌘/Ctrl+Shift+7 | 選択した各行に `1. `、`2. `… |
| **タスクリスト** | — | 選択した各行に `- [ ] ` |

どのツールもトグルです。すでにその書式のあるテキストに使うと外れます。何も選択して
いないとき、太字・斜体・コード・リンクはプレースホルダーを挿入して選択するので、
そのまま上書きできます。リストのツールは、別の種類のリストに重ねるのではなく
置き換えます。

編集はテキスト欄自身の編集として行われるので、**⌘/Ctrl+Z でツールの操作も
元に戻せます**。打った単語と同じで、やり直しで戻ります。

ツールバーは Tab では 1 か所として止まり、← → でボタン間を移動し、↓ で見出しの
メニューを開きます。コメント欄の中では、⌘/Ctrl+K はコマンドパレットを開く
代わりにリンクを作ります。Mac ではショートカットは ⌘ だけを使うので、Ctrl+B、
Ctrl+E、Ctrl+K は macOS のテキスト欄での動作のままです。文字がラテン文字でない
キーボード配列では、ショートカットは物理的な B・I・E・K キーに従います。

## リスト

リスト項目の末尾で **Enter** を押すと、次の項目が始まります — 同じ記号、次の
番号、タスクなら空の `- [ ]` — インデントもそのままです。記号の後に何もない項目で
Enter を押すと、リストを終えて記号を消します。Shift+Enter は普通の改行です。

## メンションと参照

**@** と打つと人の短い一覧が開き、打つほど絞り込まれます。**#** はプルリクエストと
イシューを番号とタイトルで一覧にします（`#42`、またはタイトル中の単語なら
`#検索語`）。↑ ↓ で選び、Enter か Tab で挿入、Esc で一覧を閉じます — 閉じるのは
一覧だけで、入力欄や周りのダイアログは閉じません。

一覧はホストに改めて問い合わせず、アプリがすでに持っているものから作ります。

| 入力欄 | @ の候補 | # の候補 |
|---|---|---|
| プルリクエスト | 作成者、レビュアー、担当者、コメントした全員 | サイドバーに読み込まれた、リポジトリのオープンなプルリクエストとイシュー |
| イシュー | 作成者、担当者、コメントした人 | 同じ |
| 新しいプルリクエスト | レビュアーと担当者の選択欄が読む人と、読み込み済みのプルリクエストの作成者 | 同じ |
| 新しいイシュー | 読み込み済みのプルリクエストとイシューの作成者 | 同じ |

単語の中の **@** や **#**（メールアドレス）、見出しの `#`、コードの中のものには
反応しません。

## 送信

⌘/Ctrl+Enter はどの入力欄からも送信します: プルリクエストやイシューのコメント、
スレッドの返信、行コメント、新しいイシューの説明。入力欄だけでなく、タブ、
ツールバー、プレビューからも動作します。Esc は同じ場所から行コメントを
キャンセルします。**スレッドの返信** は 1 行の欄なので、長い会話でスレッドごとにツールバーが増える
ことはありません。Enter で送信、Shift+Enter で改行（欄はそれに合わせて、また貼り
付けたブロックに合わせて広がります）、Esc は確認のうえで入力内容を破棄します。タブ
もツールバーもありませんが、書式のショートカットと **@** / **#** の補完は使え、送る
ものがあると **返信** ボタンが現れます。

## チートシート

各入力欄の下の **Markdown 対応** で、その場にチートシートが開きます: それぞれの
書式、そのために打つもの、ショートカット。Esc かほかの場所のクリックで閉じます。
書いている内容は動きません。

下部の **完全なガイドを開く** でこのページが開きます。ハンドブックは独立した
タブなので、そこへ移ると入力欄のあるページを離れ、送っていないテキストは失われて
しまいます。そうしたテキストがあれば — この欄でも、プルリクエストページのほかの欄
でも — アプリは先に確認します。新しいプルリクエストや新しいイシューのダイアログ
では、ハンドブックがダイアログの裏に開いてしまうため、チートシートにこのリンクは
ありません。

## 制限

- **添付ファイルなし。** ファイルをドラッグしたり画像を貼り付けたりしても
  アップロードされません。GitHub にはコメントの添付ファイル用の公開 API がなく、
  ファイルの置き場所がないためです。Web サイトでアップロードしてリンクを
  貼り付けてください。
- **読み込み済みの人と項目だけ。** @ はホストのユーザーを検索せず、# もすべての
  イシューは検索しません — 会話に参加していない人や、サイドバーが読み込んでいない
  クローズ済みのイシューは候補に出ません。名前や番号を最後まで打つことはできます。
- **変更の提案、保存済みの返信、絵文字ピッカーはありません。**
- **プレビューはアプリのレンダラーです。** アプリが描く Markdown を表示します。
  ホスト自身の表示は細部が異なることがあります（GitHub 独自の拡張、リンクになる
  メンション）。
- **プレビューはアプリの描画であり、ホストの描画ではありません。** プルリクエストと
  イシューのページでは、プレビューは投稿したコメントがアプリで表示されるとおりに
  テキストを描きます（[コメントの表示](pull-requests.md#コメントの表示)）: 同じ厳しい
  プロファイル、改行はそのまま、別サイトの画像はクリック待ち。GitHub では投稿後の
  コメントを GitHub が描くため、アプリが知らない拡張は見た目が違うことがあります。
  新しいプルリクエストと新しいイシューのダイアログは、アプリの通常の Markdown
  プレビューを使います。
- ショートカットは固定です: ショートカットの設定にはなく、そこでの割り当て変更にも
  従いません。
