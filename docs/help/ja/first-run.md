# 初回起動

GitHuttBr を初めて開くと、最初のコミットから動作に関わる数項目だけを短いウィザードが尋ねます。Git でのあなたが誰か、リポジトリのホスト先、AI を使うかどうか、そして見た目です。どのステップも空のままで構いません。設定した内容はすべて、あとから **設定** で変更できます。

![AI ステップ: このコンピューターで見つかり、テスト済みのサブスクリプション CLI](../../screenshots/onboarding-ai.webp)

## ようこそ画面

ステップの前に、ようこそ画面で別のコンピューターから **設定ファイルをインポート** できます。キーやトークンを含むファイルは、残すチェックボックスをオンにしない限りそれらが取り除かれ、パスワード付きのエクスポートはその場でパスワードを尋ねます。インポートするとファイルが適用され、ウィザードは閉じます。エクスポートの中身は [セキュリティと秘密情報](security.md) を参照してください。

## ステップ

左の列にステップが並びます。緑のチェックは入力したステップ、ダッシュは入力せずに進んだステップ、ハイライトされた行が現在のステップです。

| ステップ | 設定する内容 | あとで変更する場所 |
|---|---|---|
| Git の ID | プロファイル名と、コミットの名前・メール | 設定 → プロファイルと ID |
| アカウント | GitHub、GitLab、Azure DevOps、Bitbucket、Forgejo、セルフホストサーバーのトークンと、**このアプリで開く…** のアプリ | 設定 → 接続済みアカウント（アプリは 設定 → Git と同期） |
| 人工知能 | 使用中にした AI アカウント 1 つ | 設定 → AI |
| 外観 | テーマと、ライト・ダーク・自動のモード | 設定 → テーマ |
| 完了 | 新しい設定はなし — 設定内容のまとめ | — |

**今はスキップ** はどのステップでもウィザードを閉じ、それまでの入力を保持します。

## AI ステップ

AI は任意です。3 枚のカードから 1 つ選ぶか、**スキップ（AI なし）** を選びます:

| カード | 使うもの | 必要なもの |
|---|---|---|
| 自分のサブスクリプション | プランでサインインした Claude Code または Codex | インストール済みでサインイン済みの CLI |
| API キー | OpenAI、Anthropic、Gemini、Groq、OpenRouter、Mistral | プロバイダーのキー |
| 自分のコンピューター | ローカルで動く Ollama または LM Studio — 何もマシンの外に出ません | 起動済みのサーバー |

このコンピューターで Claude Code または Codex が見つかると、サブスクリプションのカードがどれかとそのバージョンを示し、カードを選ぶとテストします。短いプロンプトを 1 つ送り、**テスト済み: N 秒で応答。使用できます。** と表示されます。どちらも見つからない、または CLI がサインインしていない場合は、[設定 → AI](ai.md) と同じ接続設定が表示されます。

API キーやローカルサーバーでは、**続ける** がプロバイダーのモデル一覧を取得して接続をテストし、応答したアカウントだけを保存します。

このステップが保存するのは通常の AI アカウントで、設定と同じ方法で書き込まれ **使用中** になります。設定 → AI を開けばそこにあり、名前の変更、一部の機能だけでの使用、削除ができます。複数のアカウント、機能ごとのモデル、AI の書き方はウィザードではなくそちらで設定します。

## 制限

- **サブスクリプションのテストはプロンプト 1 回分です。** ほかのリクエストと同じくプランの利用分に数えられます。カードを選んだときか **再テスト** を押したときだけ実行されます。
- **検出するのは Claude Code と Codex だけです。** Gemini CLI と Devin は通常の CLI アカウントとして、設定 → AI で追加します。
- **ローカルサーバーは起動済みである必要があります。** ウィザードは Ollama や LM Studio を起動せず、モデルもダウンロードしません。
- **ウィザードは一度だけです。** 閉じたあと、設定した内容はすべて設定にあり、ウィザードを開き直す方法はありません。
