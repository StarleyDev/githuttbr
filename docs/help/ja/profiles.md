# プロファイル

プロファイルは **Git のアイデンティティ**（名前とメールアドレス）と、その
**連携トークン** を 1 つに束ねたものです。プロファイルを切り替えれば両方が同時に
変わるので、コミットの作者が正しくなり、API 呼び出しも正しいアカウントを使います。

同じマシンで仕事用と個人用のリポジトリを扱うとき、あるいは GitHub のアカウントを
2 つ持っているときに便利です。

## プロファイルを編集する、プロファイルを使う

設定のうち 2 つのページはプロファイルごとに変わります — **プロファイルと ID** と **接続済みアカウント** で、見出しに編集中のプロファイル名が出る **あなた** グループの先頭にあります。ほかのページはどのプロファイルでも共通で、ページ上部にそう表示されます。

**プロファイルと ID** の先頭はプロファイルのカードです。画像、名前（その場で編集）、アプリが使用中なら *使用中*、切り替え、**新しいプロファイル**。**接続済みアカウント** の先頭には同じ切り替えが *編集中のプロファイル* のバーとして表示されます。切り替えで選ぶのは**編集する**プロファイルで、アプリが**使う**プロファイルは変わりません。両者が異なるときは琥珀色の帯がそれを知らせ、**このプロファイルを使う** で切り替えられます。アカウントを別のプロファイルに結び付けてしまいやすいのはこの瞬間なので、接続済みアカウント は各カードとボタン自体にもプロファイル名を表示し、確認でも繰り返します。プロファイルの削除も同じ場所にあり、先に確認します。

カードの下には git の ID とコミット署名が続きます。開いているリポジトリが別の人としてコミットする場合 — その git 設定が別の作成者を指している場合 — はその旨の行と **この身元情報を現在のリポジトリに適用** が表示されます。一致していれば適用するものはなく、行は出ません。続いてプロファイル画像、**接続済みアカウント**の一覧 — ホストごとに *接続済み*、*トークンの期限切れまたはエラー*、*接続できません*、*未接続* のいずれかと、そのホストで 接続済みアカウント を開く **接続** または **更新** — そしてプロファイルが使う AI が表示されます。

一覧は、ページを開くたびとトークンが変わるたびに、サインイン画面を出さずに静かに確認します。定期的に問い合わせることはありません。その結果はサイドメニューも使います。トークンが拒否されたり確認に失敗したりすると **接続済みアカウント** に小さな警告数が付きます — 設定がすでに行った確認についてだけです。到達できないホストは数えません。トークン自体は問題ないかもしれないからです。

## AI は共有される

プロファイルが独自の AI を持つ必要はありません。1 つの[共通の
AI](ai.md#全プロファイル共通の-ai) がすべてのプロファイルに応え、
プロファイルは必要なときだけ独自の AI に切り替えます。
この選択はすべてに及びます：共通の AI を使うプロファイルは、書き方も共通の
AI の設定どおりになります（コミットのスタイル、コミット用の追加ルール、
リポジトリチャット）。別のスタイルが必要なプロファイルは独自の AI
を持ちます。これは共通の AI のコピーで、あとから変更できます。すべて
**AI** ページで編集し、プロファイルページはそのプロファイルがどの AI
を使うかを示して、そこへリンクするだけです。

## プロファイルごとに自分のアカウント

プロファイルはトークンのほかに、マシン上にすでにあるログイン（git の credential
helper や GitHub CLI）を 設定 → 接続済みアカウント で**連携**できます。連携は1つのプロファイル
だけのものです。新しいプロファイルは未接続から始まり、ほかのプロファイルが
すでに持っているアカウントは拒否されるので、2つのプロファイルに2つの GitHub
（または Azure DevOps）アカウントを並べて持てます。[ホスティング](hosting.md) を
参照してください。

## リポジトリごとの紐付け

リポジトリは **プロファイルに紐付ける** ことができます。そうすると、そのリポジトリ
のバックグラウンドフェッチは常に正しいアカウントで認証されます — あなたがもう一方の
アカウントに属するリポジトリを眺めている最中でも同じです。

トークンは [OS のキーチェーン](security.md) に置かれ、設定ファイルには決して入り
ません。
