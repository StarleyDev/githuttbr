# プロファイル

プロファイルは **Git のアイデンティティ**（名前とメールアドレス）と、その
**連携トークン** を 1 つに束ねたものです。プロファイルを切り替えれば両方が同時に
変わるので、コミットの作者が正しくなり、API 呼び出しも正しいアカウントを使います。

同じマシンで仕事用と個人用のリポジトリを扱うとき、あるいは GitHub のアカウントを
2 つ持っているときに便利です。

![プロファイル。片側に git のアイデンティティ、もう片側にその連携トークン](../../screenshots/settings-profiles.webp)

## プロファイルを編集する、プロファイルを使う

設定はページを 2 つに分けています。**このプロファイル** には、プロファイルと
一緒に変わるページ — **プロファイル** と **連携** — があります。**アプリ** には
それ以外のすべてがあり、どのプロファイルでも適用されることがページの上部に
書かれています。

2 つのプロファイルのページは、*編集中のプロファイル* とピッカーのバーで始まります。
ピッカーが選ぶのは **編集する** プロファイルで、アプリが **使っている**
プロファイルは変わりません。両者が違うときは琥珀色の帯がそれを伝えます —
*仕事 を編集しています。アプリは 個人 を使用中です* — そして
**このプロファイルを使う** で切り替えられます。アカウントを間違ったプロファイルに
連携しやすいのはまさにこのときなので、連携のページもすべてのカードとボタン自体に
プロファイル名を表示します：**プロファイル 仕事 にリンク**。確認画面でも繰り返されます。
新規作成と削除も同じバーにあり、削除は先に確認します。

![アプリが別のプロファイルを使っている間に Work プロファイルを編集：琥珀色の帯と、Work の名前が入ったリンクボタン](../../screenshots/settings-profile-band.webp)

## AI は共有される

プロファイルが独自の AI を持つ必要はありません。1 つの[共通の
AI](ai.md#全プロファイル共通の-ai) がすべてのプロファイルに応え、
プロファイルは必要なときだけ独自の AI に切り替えます。
この選択はすべてに及びます：共通の AI を使うプロファイルは、書き方も共通の
AI の設定どおりになります（コミットのスタイル、コミット用の追加ルール、
リポジトリチャット）。別のスタイルが必要なプロファイルは独自の AI
を持ちます。これは共通の AI のコピーで、あとから変更できます。すべて
**AI** ページで編集し、プロファイルページはそのプロファイルがどの AI
を使うかを示して、そこへリンクするだけです。

## プロファイルごとに自分のアカウント

プロファイルはトークンのほかに、マシン上にすでにあるログイン（git の credential
helper や GitHub CLI）を 設定 → 連携 で**連携**できます。連携は1つのプロファイル
だけのものです。新しいプロファイルは未接続から始まり、ほかのプロファイルが
すでに持っているアカウントは拒否されるので、2つのプロファイルに2つの GitHub
（または Azure DevOps）アカウントを並べて持てます。[ホスティング](hosting.md) を
参照してください。

## リポジトリごとの紐付け

リポジトリは **プロファイルに紐付ける** ことができます。そうすると、そのリポジトリ
のバックグラウンドフェッチは常に正しいアカウントで認証されます — あなたがもう一方の
アカウントに属するリポジトリを眺めている最中でも同じです。

トークンは [OS のキーチェーン](security.md) に置かれ、設定ファイルには決して入り
ません。
