# リポジトリ wiki

リポジトリを指定すると、そのコードベースを解説する短い wiki を書き上げます。

## リポジトリカード

- **言語の内訳** — バイト数によるもの。
- **スタック** — フレームワークをバッジで表示します（Next、Angular、Electron、
  Tailwind…）。
- **依存関係** — マニフェスト（`package.json`、`Cargo.toml`、`go.mod`、
  `pyproject.toml`、`pubspec.yaml`、`Gemfile`…）から直接読み取り、アーキテクチャ上の
  役割ごとにまとめます。足場にあたるもの — 型スタブ、ローダー、lint プラグイン — は
  先に取り除かれ、プロジェクトが実際に宣言しているパッケージだけが現れます。
- **モジュール依存グラフ** — ソース（JS/TS、Python、Go、Rust、Dart、Ruby、C/C++、
  PHP）を解析し、リポジトリ自身のファイルに対して解決するので、パッケージの import
  が偽の辺になることはありません。

## 書かれるページ

GitHuttBr はリポジトリが追跡しているファイルから数ページ分の構成を立て — まずドキュ
メントとマニフェスト、次に変更の多いもの — 各ページをそれが扱うファイルから書き
起こします。

**あらゆる記述には出典となったファイルが添えられ**、どのファイルにも裏付けられない
主張は公開されずに却下されます。ページは並行して書かれ、まとめて一度に保存されるので、
失敗した実行が良い wiki を置き換えてしまうことはありません。wiki が古いコミット時点で
書かれた場合は、そのことを伝えます。

## バックグラウンドでの生成

wiki を書くには時間がかかります — 1 ページにつき 1 回のモデル呼び出しです。
実行はページではなくアプリに属します。wiki を離れて別のタブや別のリポジトリに
移っても、実行は続きます。戻ってくるとページは進み具合を表示し（*ページの構成を
考えています…*、続いて仕上がったページから順に）、**ウィキを生成** は押せない
ままになるので、2 度目のクリックで競合する 2 つ目の実行が始まることはありません。
*ウィキを生成しました* の通知は、どこにいても届きます。

**キャンセル** で止められます。失われるものはありません。以前の wiki はすべての
ページが書き終わってから初めて置き換えられるので、キャンセルした実行はそれを元の
ままに残します。キャンセルは進行中のリクエスト — HTTP 呼び出し、CLI アカウント
なら CLI プロセス — を終了させますが、プロバイダーはそれまでに生成したトークン
分をそれでも請求することがあります。

ウィンドウを閉じると、そのウィンドウが開始した実行はキャンセルされます。

## エクスポート

**エクスポート** は全体を `docs/wiki/` にリンク付き Markdown として書き出します
— コミットでき、PR でレビューでき、ホスティング先で読めるようになります。
ツールチップには書き出し先のフォルダーが表示されます。

隣のフォルダーアイコンで、このリポジトリ用に **別のフォルダー** を選べます —
リポジトリ内のどのフォルダーでも構いませんが、ルート（エクスポートの `README.md`
がプロジェクト自身のものを置き換えてしまう）と `.git` は除きます。もう一度
`docs/wiki` を選ぶと既定に戻ります。

### すでにリポジトリにある wiki

このマシンにそのリポジトリ用の wiki がない場合 — チームメイトのマシンで生成された、
あるいは再インストール前に生成された場合 — ページは代わりに wiki フォルダーにある
ものを読み込み、その旨を表示します。判定はそこに刻まれたコミットに基づきます。
そのコミット時点では最新、それ以降は遅れている、という扱いです。

読み戻した wiki が持てないもの: それを書いたモデル、そしてこのバージョンがスタック
とページの種類を刻むようになる前のエクスポートに由来するもの — そうしたページは
スタックカードのない、ただのモジュールとして表示されます。手で編集したページは
編集済みとして表示されますが、その **出典** リストには、エクスポートが書く形式の
ままの行しか残りません。**再生成** は新しい wiki を書いてこのマシンに保存し、
以後はそちらが優先されます。

読み戻した wiki での **削除** はリポジトリからそれを削除するので、事前に確認が
あります。削除されるのはエクスポートが書いたファイル — *Generated by* の注記が
付いています — だけで、フォルダー内のほかのものは残ります。コミット済みの
ファイルは git で戻せますが、未コミットのものは戻せません。

秘密情報らしきファイルが送られることはありません。
