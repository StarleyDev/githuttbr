# Перший запуск

Під час першого запуску GitHuttBr короткий майстер питає те небагато, що змінює його поведінку з першого коміту: хто ви в Git, де розміщені ваші репозиторії, чи потрібен ШІ та який вигляд обрати. Будь-який крок можна лишити порожнім, а все, що він задає, згодом змінюється в **Налаштуваннях**.

![Крок ШІ: CLI з підпискою знайдено на цьому комп’ютері й перевірено](../../screenshots/onboarding-ai.webp)

## Екран вітання

Перед кроками екран вітання пропонує **імпортувати файл налаштувань** з іншого комп’ютера. Ключі й токени з файлу вилучаються, якщо не позначити прапорець, щоб їх зберегти, а експорт із паролем просить пароль одразу там. Імпорт застосовує файл і закриває майстер — що містить експорт, див. у [Безпека та секрети](security.md).

## Кроки

Ліва колонка показує кроки. Зелена позначка — заповнений крок, риска — пройдений без заповнення, а підсвічений рядок — поточний.

| Крок | Що задає | Де змінити потім |
|---|---|---|
| Ідентичність Git | Назву профілю, а також ім’я та email у комітах | Налаштування → Профіль та ідентичність |
| Облікові записи | Токени GitHub, GitLab, Azure DevOps, Bitbucket, Forgejo і власних серверів, а також застосунок для **Відкрити за допомогою…** | Налаштування → Підключені облікові записи; застосунок — у Налаштування → Git і синхронізація |
| Штучний інтелект | Один обліковий запис ШІ, зроблений використовуваним | Налаштування → ШІ |
| Вигляд | Тема та світлий, темний чи автоматичний режим | Налаштування → Теми |
| Готово | Нічого нового — підсумок налаштованого | — |

**Поки що пропустити** закриває майстер на будь-якому кроці й зберігає вже введене.

## Крок ШІ

ШІ необов’язковий. Оберіть одну з трьох карток або **Пропустити, без ШІ**, що вимикає ШІ,
доки ви не налаштуєте його в [Налаштування → ШІ](ai.md):

| Картка | Що використовує | Що потрібно |
|---|---|---|
| Моя підписка | Claude Code або Codex із входом за вашим тарифом | Встановлений CLI з виконаним входом |
| API-ключ | OpenAI, Anthropic, Gemini, Groq, OpenRouter або Mistral | Ключ від провайдера |
| На моєму комп’ютері | Ollama або LM Studio локально — ніщо не залишає машину | Запущений сервер |

Якщо на комп’ютері знайдено Claude Code або Codex, картка підписки називає його та версію, а вибір картки його перевіряє: один короткий промпт, потім **Перевірено: відповідь за N с. Готово до роботи.** Якщо нічого не знайдено або CLI без входу, картка показує те саме налаштування з’єднання, що й [Налаштування → ШІ](ai.md).

Для API-ключа чи локального сервера **Продовжити** перевіряє з’єднання, запитуючи список моделей, і зберігає лише обліковий запис, що відповів.

Крок зберігає звичайний обліковий запис ШІ — так само, як його пишуть Налаштування, — з позначкою **Використовується**: відкрийте Налаштування → ШІ, і він там, його можна перейменувати, використовувати лише для частини функцій або видалити. Кілька облікових записів, модель для кожної функції та стиль ШІ налаштовуються там, а не в майстрі.

## Обмеження

- **Перевірка підписки коштує одного промпту.** Вона зараховується до вашого тарифу, як будь-який запит. Запускається лише при виборі картки або натисканні **Перевірити знову**.
- **Розпізнаються лише Claude Code і Codex.** Gemini CLI та Devin працюють як звичайні CLI-облікові записи, які додаються в Налаштування → ШІ.
- **Локальний сервер уже має працювати.** Майстер не запускає Ollama чи LM Studio і не завантажує моделі.
- **Майстер запускається один раз.** Після закриття все задане живе в Налаштуваннях; відкрити майстер знову не можна.
